# 项目结构

更新日期：2026-10-07。本页描述当前代码的职责和定位方式；整理过程见[实施计划](开发记录/项目维护/2026-10-07-项目结构整理-实施计划.md)。结构整理及后续前端UI和体验修复均已通过用户验收，阶段01适用范围75/79项收尾完成，四项条件性邮件/公开注册继续暂缓；[阶段02](开发阶段/阶段02-统一任务与模型调用.md)具备启动条件，尚未开始开发。

## 顶层目录

```text
paperassist-system/
├─ backend/                  Python 应用、迁移、运维入口及后端测试
├─ frontend/                 React 应用、静态资源及前端测试
├─ script/                   Windows 启停、账号初始化入口及其实现
├─ docs/                     需求、结构说明、开发阶段及交付记录
└─ reference-projects/       本地外部参考源码，Git 忽略
```

依赖目录、缓存、编译产物、日志和本地配置均由 `.gitignore` 排除。`backend/data/`、`backend/backups/` 和 `script/.runtime/` 是本机运行/验证数据，不属于源码，也不随代码分层搬迁。

## 后端

```text
backend/
├─ app/
│  ├─ main.py                FastAPI 组装和启动生命周期
│  ├─ manage_users.py        本机账号管理 CLI
│  ├─ api/                   HTTP 路由、请求依赖、上传限制
│  ├─ domain/                分析计算、成果组装、任务轮询及业务规则
│  ├─ adapters/              PostgreSQL 存储、Excel、OpenAI、Word 适配
│  ├─ auth/                  认证、会话、密码及撤销审计
│  ├─ core/                  配置、路径和公共错误契约
│  ├─ db/                    连接、权限、版本检查及表结构
│  └─ maintenance/           离线导入、审计、迁移报告与恢复演练
├─ alembic/                  env 和已提交的数据库 revision
├─ scripts/                  离线维护的命令行脚本入口
├─ tests/                    api/auth/db/domain/adapters/maintenance/integration
│  ├─ conftest.py            测试库隔离等共享 fixture
│  └─ helpers/               认证等共享测试辅助
├─ data/                     原始 Excel、PNG、DOCX（本地）
└─ backups/                  数据库与资产备份（本地）
```

`api` 负责 HTTP 语义，调用 `domain` 和适配器；`domain` 不导入 HTTP 路由模块。`adapters` 处理外部格式/服务和持久化，部分适配器复用纯业务内容模型。`auth` 保留自己的路由、服务和中间件，以免把一个内聚模块重新打散。`maintenance` 是真实运维能力，不因应用启动时不导入就视为无用代码。

| 要找的功能 | 位置 |
| --- | --- |
| 项目、上传、下载和语言接口 | `app/api/projects.py` |
| Excel 读取和安全限制 | `app/adapters/excel.py`、`app/api/excel.py` |
| 字段检查和描述统计 | `app/domain/analysis.py`、`descriptive.py`，对应 `app/api/` 路由 |
| 箱线图、解释和报告 | `app/domain/boxplot.py`、`explanations.py`、`reports.py`，对应 `app/api/` 路由 |
| OpenAI SDK 和 Word 格式 | `app/adapters/openai_plot.py`、`openai_explanation.py`、`report_docx.py` |
| 持久化和资产管理 | `app/adapters/storage.py`、`explanation_store.py`、`report_store.py` |
| PostgreSQL 连接和表定义 | `app/db/database.py`、`schema.py` |
| 运行配置和目录定位 | `app/core/config.py`、`paths.py` |

`main.py` 与 `manage_users.py` 是有外部调用方的入口，保留在包根目录；`__init__.py` 是 Python 包标记。没有创建未来的 worker/workflows 空目录，没有保留旧布局的转发模块。

## 前端

```text
frontend/src/
├─ main.tsx                  页面唯一入口
├─ app/                      App 组合、全局基础样式、应用样式
├─ features/
│  ├─ auth/                  登录、改密、界面语言
│  ├─ projects/              项目列表、分区导航、详情、摘要和选择状态
│  ├─ files/                 Excel 上传预览
│  ├─ analysis/              命名流程导航、字段配置和描述统计
│  ├─ figures/               箱线图任务和展示
│  ├─ explanations/          分析解释
│  └─ reports/               Word 报告
├─ shared/
│  ├─ api/                   请求客户端、会话与项目访问实例
│  ├─ components/            鉴权下载等跨功能组件
│  └─ i18n/                  语言状态与公共/流程/错误词典
└─ test/
   ├─ integration/           跨认证、项目和分析流程的测试
   └─ fixtures/              多个测试共用的合成数据
```

组件测试与功能放在一起；真正跨功能的用例进入 `test/integration`。请求客户端和语言状态各只有一个真实模块实例，避免出现移动后新旧路径各自保存会话状态的问题。CSS 保持基础样式先于应用样式加载；UI改版新增的工作台、项目内容、分析流程和成果样式放在对应功能目录。ProjectResources负责同一项目内文件与分析区域的挂载，AnalysisWorkflow负责命名流程的显示，切换导航不会卸载业务组件。

## 脚本与稳定入口

```text
script/
├─ dev.cmd                   日常 start / status / stop
├─ setup-database-roles.cmd  新环境运行账号初始化
├─ dev/                      PowerShell 控制器与 Windows 进程树实现
├─ database/                 交互式数据库角色设置实现
├─ tests/                    脚本单元测试
└─ .runtime/                 状态、日志及本地验证材料（Git 忽略）
```

以下命令从项目根目录调用，入口保持不变：

```powershell
.\script\dev.cmd start
.\script\dev.cmd status
.\script\dev.cmd stop
```

数据库 CLI 的当前模块路径已调整；以下只读命令从 `backend` 目录执行：

```powershell
.\.venv\Scripts\python.exe -m app.db.database check
.\.venv\Scripts\python.exe -m app.maintenance.database_audit
```

| `app.db_schema` | `app.db.schema` |
| `app.database_audit` | `app.maintenance.database_audit` |

| 根目录的业务组件 | `src/features/` 对应功能目录 |
| `script/dev.ps1`、`process-tree.cs` | `script/dev/` 下的同名文件 |

历史实施/验收记录中的命令和代码名保留当时上下文；查询当前代码用本页和 README。恢复演练读取旧版本代码时仍使用那个版本自身的布局，不能拿当前模块路径去修改导出的旧代码。

## 清理范围

| 删除内容 | 依据 |
| --- | --- |
| `frontend/src/assets/hero.png`、`react.svg`、`vite.svg` | 全仓源码没有 import、URL 或动态资产引用；生产依赖图不包含这些模板资源 |
| `frontend/public/icons.svg` | 页面、组件和样式无引用，为模板 sprite |
| `.counter`、`.hero`、`#center`、`#next-steps`、`#docs`、`#spacer`、`.ticks` 等模板样式 | 当前 HTML/组件没有对应元素，也没有动态注入 |
| 旧 `.project-selection` 样式及模板专用变量 | 当前项目列表已使用其它选择器，专用变量没有剩余使用方 |

保留正在引用的 `public/favicon.svg`、动态状态样式、所有业务模块、词典和运维工具。4个素材已从仓库移除，仓库外的临时目录保留可恢复副本。资源清理依据仓库内引用；无法判断是否有仓库外用户收藏过旧模板素材直链。没有把本地数据、备份、配置或测试资料作为“幽灵文件”删除。
