## 支持内容

| 范围 | 当前支持 | 使用限制 |
|---|---|---|
| 项目 | SCI与毕业论文两类项目、文件/任务/来源/稿件及版本关联 | 账号所有权控制研究内容；管理员身份不授予跨账号研究资料读取权限。 |
| 输入 | `.xlsx`、`.docx`、`.pdf`、`.png`、`.jpg/.jpeg` | 单文件部署上限10MiB，可由已批准配置进一步降低；XLSX还受解压、行列、单元格上限限制，格式扩展名不代表内容必然有效。 |
| 本地解析 | OpenXML文档/表格、PDF文本与受限CPU OCR、来源定位、OCR复核 | OCR固定模型与输入限制；低置信、无法辨认及解析失败需要人工处理，不将猜测当原文。 |
| 描述/相关 | 描述统计；Pearson、Spearman，成对或矩阵 | 完整案例和方法前提按实际任务合同执行；探索性矩阵不等于预先确认假设检验。 |
| 组间/配对 | Welch t、Mann–Whitney U、配对t、Wilcoxon、Welch ANOVA、Kruskal–Wallis；适用时Holm校正 | 比较设计、组别及配对必须明确；最多6组、10000条记录或完整对，不能用选方法替代研究设计核对。 |
| 建模 | OLS、Logistic、ROC/AUC、Kaplan–Meier | 当前有限方法集，非任意统计代码；秩亏、分离、收敛、数值不稳定等保持失败/待核对，不造结果。建模最多10000行、20个展开效应项，具体任务合同可更严。 |
| 图表与稿件 | 固定数据/配置/来源的图表与报告、事实稿、写作授权链、公共稿件新版本、意见分类及有限返修/多轮回传 | 原版本保留；新版本不覆盖已冻结任务、调用或结果未知状态。模型环节须另行明确授权，本批不作真实模型质量结论。 |
| 学校模板 | 用户提供的DOCX模板及补充材料，提取规则/章节、冲突确认、固定版本绑定 | 不是全校模板库；学校、院系、专业、层次及适用版本由使用者确认。真实学校材料、完整Word/WPS逐页验收缺口仍保留。 |
| 导出 | DOCX；固定该DOCX校验值后由本地renderer生成PDF；相关项目成果下载 | Word为可编辑成果；不同Office/WPS/字体环境的分页不承诺一致。字段、目录、字体和页数按具体输出检查。 |
| 语言 | 界面简体中文/英语；输出语言与项目/具体任务设置关联 | 本批新增状态文案双语核对不等于全库所有历史错误文本已穷尽验证；历史输出不自动翻译或重写。 |
| 运行治理 | 已批准配置版本、用户/项目容量、队列/服务观察、维护准入、工作进程并发1或2 | 保存/激活的期望值与进程启动实际值分开；显式维护和重启生效，未观察到的值显示未知。 |

运行限制来自当前合同：`backend/app/core/config.py`、`backend/app/domain/fixed_statistics_contract.py`、各统计`contracts.py`、`documents/ocr_contracts.py`及`school_templates/contracts.py`。这些是产品输入/资源边界，不是性能测量成绩。

## 当前部署与验证边界

第四批只面向本机隔离的非付费内测。API/静态网页、Worker、dispatcher、PostgreSQL、RabbitMQ和PDF renderer按独立容器实例部署；数据库与消息端口不对宿主开放。TLS使用本地CA及匹配SAN的证书，客户端明确校验该CA；用户另行授权仅导入本批CA至CurrentUser/Root，未改计算机级信任；本地证书不等于公网证书。

两类合成路径、本地数值计算、真实本地渲染、工程定向测试、真实研究验证、用户验收和发布是不同证据。合成外部响应须有明确标识，不代表真实模型、期刊/学校适配或收费结果。第四批没有真实模型、NCBI/期刊查询、供应商删除或支付调用。

采样默认15秒，超过45秒为陈旧/未知。维护拦截新增业务写入，已有任务可自然完成；保存成果入口保留，实际读取仍依赖身份、数据库和存储可用。维护标志本身不证明备份已停写，必须按手册排空和停服。状态观察不触发自动修复、重投或删除。
