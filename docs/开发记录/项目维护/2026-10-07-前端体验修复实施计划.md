# 前端体验修复实施计划

日期：2026-10-07。6项体验修复及侧栏切页动效优化已完成开发验证并通过用户验收；服务已停止，按用户本次授权纳入阶段01收尾统一提交推送。阶段02具备启动条件，尚未开始开发。结果见[交付记录](前端体验修复交付记录.md)。

**目标：** 修复分区定位、预览反馈、成果刷新、错误状态及账号菜单问题，统一按钮反馈和切页动效。

**方案：** 沿用React状态与当前组件，保留隐藏页面中的草稿、请求及成果；用CSS过渡和短暂入场动画，不引入动效依赖，不通过重新挂载整个工作区实现动画。页面切换时先定位新内容，使用约180ms淡入及小幅位移；侧栏宽度、内容边距和顶部栏同步过渡。系统减少动态效果时关闭动画。

**技术：** React、TypeScript、CSS、Vitest / Testing Library，浏览器以模拟接口合成数据验证。

## 约束

- 保持白灰底、深紫主色；不展示系统编号、哈希、内部版本。
- 仅修改必要的前端逻辑与样式，不改后端、数据库、模型配置，不调用收费API。
- 通过现有返回/重读机制修复，不添加路由库、全局任务系统、轮询或复杂状态管理。
- 回归测试先复现再修复；纯视觉变化用实际浏览器验证，不写镜像CSS实现的测试。
