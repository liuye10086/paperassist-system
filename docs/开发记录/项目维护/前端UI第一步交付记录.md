## 本轮修改

- 整体样式采用白灰底、深紫主色，统一字体、控件、焦点与窄屏布局。移除已被替代的旧全局、登录和列表样式。
- 新增工作台侧栏与项目入口，首页最近研究卡使用真实项目数据；项目列表保留搜索、类型筛选、分页、重试及五项已有信息，项目名称可点击打开。
- 新建项目改为弹窗，名称、类型、主题仍必填；取消保留草稿，成功后清空并打开新项目。支持Tab约束、Escape关闭和回焦；创建请求进行中保持焦点在弹窗。
- 登录与密码恢复使用统一品牌布局；顶部保留语言设置，账号菜单收纳改密与退出。保留会话恢复、超时、失效、多标签同步与原请求控制。
- 新增文案已注册中英文。新页面不展示系统编号或哈希，不用虚构进度替代真实数据。
