## 冻结接口（前后端共同使用）

基址：`/api/v1/projects/{project_id}/files/{file_id}/dataset-versions/{dataset_id}`，dataset_id可以是原始或整理版本，服务端统一复用`load_dataset`核对归属与来源。

`GET {base}/profile`：

```typescript
type Profile = {
  schema_version: 1; rules_version: 'excel_profile_v1';
  source: DatasetAnalysisSource; filename: string; sheet_name: string;
  data_range: string | null; record_count: number; blank_row_count: number;
  duplicate_groups: number; duplicate_rows: number; duplicate_extra_rows: number;
  fields: FieldProfile[];
};
type FieldProfile = {
  column: number; letter: string; name: string;
  unit: {status: 'confirmed' | 'unconfirmed'; value: string | null};
  type_counts: Record<string, number>; missing_count: number;
  non_missing_count: number; distinct_count: number;
  numeric: null | {
    status: 'ok' | 'unavailable'; n: number;
    mean: number | null; std: number | null; min: number | null; max: number | null;
    q1: number | null; median: number | null; q3: number | null; iqr: number | null;
    lower_fence: string | null; upper_fence: string | null;
    outlier_count: number; warnings: string[];
  };
  categories: null | {
    distinct_count: number; top: {kind: 'text' | 'boolean'; value: string | boolean; count: number}[];
    other_count: number;
  };
  temporal: {kind: 'date' | 'datetime' | 'time' | 'duration'; count: number; min: string; max: string}[];
  time_candidates: {valid_count: number; invalid_count: number; ambiguous_count: number};
  issue_counts: Record<string, number>;
};
```

类型计数只含非缺失单元格；distinct_count对非缺失的带类型值去重。categories只统计文本/布尔子集，候选时间文本仍属于文本。数值n是实际数值数；所有摘要指标统一为JSON有限数值或null，错误不能产生NaN/Infinity。warnings使用固定代码`numeric_precision`、`numeric_unavailable`、`std_insufficient`、`metric_unavailable`，不直接输出后端异常文本。

`GET {base}/profile/issues?kind=missing&column=2&page=1&page_size=20`：

```typescript
type IssueKind = 'missing' | 'outlier' | 'mixed_type' | 'error' | 'formula'
  | 'time_candidate' | 'time_invalid' | 'time_ambiguous' | 'numeric_precision' | 'duplicate';
type IssuePage = {
  source: DatasetAnalysisSource; rules_version: 'excel_profile_v1';
  kind: IssueKind; column: number | null; page: number; page_size: 20; total: number;
  items: {row: number; column: number | null; coordinate: string | null;
    kind: string | null; value: string | boolean | null;
    group_first_row: number | null; group_size: number | null}[];
};
```

除duplicate外必传所属列号，duplicate不传列号。缺失位置含稀疏未存储格，按原始行排序分页，不能展开全行列矩阵。混合类型位置列出该混合字段所有非缺失成员，界面说明为类型组成，而非认定每个值错误。重复项按首行分组、组内原行号排列，包括首行在内的全部成员，total为涉及行数；前端通过group_first_row及group_size显示组与位置，不生成新业务标识。时间候选/歧义/无效可分别查看。

位置读取沿用原始`dataset-versions/{id}/rows`或整理`prepared-dataset-versions/{id}/rows`，20行；前端核对来源/版本及请求位置。概况组件接受明确选定的版本来源，切换版本清空旧概况/问题/行选择，旧响应不能覆盖新版本。
