## 设计与取舍

当前`dataset_versions`通过结构/文件/version复合外键和每结构每Sheet唯一约束保存原始解析输出，不能直接插入清洗版。另建整理表比松动这些约束更小；原始数据版本、旧分析及下游成果的读取仍走原路径。

只做表头区域会缺少已确认的清洗闭环；引入完整工作流库或通用清洗引擎会扩大本步。选用真实业务检查点：执行器每次从持久checkpoint决定下一个节点，已批准候选直接发布，不重算预览。该选型依据阶段02已确认承接方案中“具体字段和工作流库选型在对应业务设计时确定”；不声称已接入LangGraph。

### 规则及生效数据

规则合同名`PreparationRecipe`：

```json
{"header_row":3,"data_range":"C5:D35","fields":[
 {"column":3,"name":"测量值","unit":{"status":"confirmed","value":"mg/L"},"trim_text":false,"missing_markers":["NA"]},
 {"column":4,"name":"组别","unit":{"status":"unconfirmed","value":null},"trim_text":true,"missing_markers":[]}
]}
```

- 表头行位于数据区之前，同一列范围；允许中间说明行。区域内全部行计入记录，内部和末端空行保留，区域之外不会进入此次统计；原坐标如C5保持C5，不重排成A2。
- 字段覆盖区域全部列，原列序排列；同名允许，字母消歧，空原表头提供可编辑候选名。用户修改字段名只影响整理版，不修改原始标题格。单位默认未确认；显式确认空字符串代表无单位，其他确认值仅为标签，不换算数值。
- 仅处理text：先按列trim，再精确、区分大小写匹配用户指定标记并改为缺失。全部操作默认关闭，未选择的列不处理。数值、日期、公式、错误和布尔值保持原类型；公式仍不可直接统计，缓存不转事实。
- 合并区域显示相关提示，覆盖格不补值；不因一个合并格拒绝整个预览。保留既有数字精度与有效记录检查。
- `PreparedDatasetObject`保存`schema_version:1`、完整原始`parent_source`、`transform_version:'excel_prepare_v1'`、recipe及`PreparedSheet`；后者保存原index/name、范围、字段、稀疏生效单元格`{row,column,coordinate,kind,value}`。原XML/公式/cache通过父版本读取，无需重复原始证据字段。对象总量仍限制4MiB。
- 预览给出区域记录数、操作影响单元格/行数、按列计数、前20条差异及未解决提示；明确有限展示并提供完整候选JSON下载。生效行可按20行分页。未解决公式/混合类型可保存整理版，但后续字段检查仍明确拒绝不适用列。

### 稳定来源与分析

原`DatasetAnalysisSource`保持原JSON；新增`PreparedDatasetAnalysisSource`沿用其13个字段，`kind='prepared_dataset_version'`，增加`parent_dataset_id`、`parent_dataset_version`及`transform_version='excel_prepare_v1'`。数据集id/version/hash/size指整理对象，file/structure/sheet/parser仍指原始来源；完整父来源在不可变对象中固定。中央`AnyDatasetAnalysisSource`联合类型与`source_dict`供配置、任务和成果复用，不逐消费者另造来源协议。

`load_dataset`支持原始和整理id，返回匹配对象；整理扫描按已确认区域与真实列字母计算，复用已有统计数值规则和`DATASET_ENGINE`。整理字段名作为统计名称；已确认单位供分析配置默认填入，分析单位仍为显式保存的展示标签，不换算，整理版单位元数据不被回写。生成整理版不自动修改当前分析配置，用户显式选定并保存后才改绑。

来源展示为“原始数据vM · 整理数据vN”。图表、解释、Word及任务完整透传新来源，旧v1/v2任务保持。外发摘要仅整理数据采用version3，展示原始/整理版本；v1/v2摘要与授权计算保持，实际模型prompt/payload不因本地版本改变。

### 任务、决定和检查点

新增任务`prepare_dataset`，workflow_version=`dataset_preparation_v1`；初始快照固定项目/文件/完整原始source及初始recipe。输入版本为`{kind:'dataset_preparation',source:<原始source>,workflow_version:'dataset_preparation_v1'}`。规则后续变化保存在追加的决定与checkpoint，不改初始快照。

新增三张表（迁移`0017_dataset_preparation`）：

1. `task_checkpoints`：任务、seq、workflow_version、next_node、state_json、创建时间；一任务seq唯一。state包含输入版本、recipe_revision、recipe、候选对象引用/摘要、批准决定或结果引用，大对象不放DB。
2. `dataset_preparation_decisions`：任务、wait/checkpoint、执行人、approve/revise、修正规则、输入版本、幂等键/摘要、接收时间及首次响应；同一wait只接受一次决定。
3. `prepared_dataset_versions`：固定原始dataset父引用、文件、发布task/decision、同一原始dataset的整理序号、对象/hash/size、规则/摘要、创建人及时间。一任务只发布一次。

执行流：

```text
create -> checkpoint(next=prepare_preview) -> queued
prepare_preview -> 保存候选对象 -> 原子写checkpoint(next=await_confirmation)、wait及任务waiting_confirmation -> 结束attempt并返回
approve -> 同事务写决定、checkpoint(next=publish)、resolve wait、queued/outbox
revise -> 同事务写决定及新规则、checkpoint(next=prepare_preview)、resolve wait、queued/outbox
publish -> 读取批准候选，不重算 -> 同事务发布整理版本、checkpoint(next=done)及task succeeded
```

等待类型`dataset_preparation_confirmation`，原因`confirmation_required`复用现有合法状态。独立决定接口携带`expected_task_revision`、`wait_id`、`checkpoint_id`和固定input_version；操作为approve或revise，后者带完整recipe。陈旧或不同内容重复提交返回既有冲突模式，不产生第二次发布。复用现有60秒租约与outbox恢复，等待不占Worker；不要求原始source是最新版本。

### HTTP/UI冻结接入

由`DatasetPreparationService`提供下列接口，实际标准字段见任务简报；旧接口不改变：

- `GET /api/v1/projects/{project}/files/{file}/dataset-versions/{raw_id}/preparation-defaults?header_row=...&data_range=...`：只读生成字段候选及原始source，不自动开始任务；省略区域时提供待核对默认值。
- `POST /api/v1/projects/{project}/files/{file}/dataset-preparations`：`{dataset_id,recipe}`及Idempotency-Key，返回TaskView（新建202，重复200）。
- `GET /api/v1/tasks/{task}/dataset-preparation`：任务、source、当前checkpoint、规则、差异摘要、候选下载URL及已发布整理摘要；task中心复用同一面板。
- `POST /api/v1/tasks/{task}/dataset-preparation/decision`：版本化approve/revise，返回TaskView202，幂等重放保留首次响应。
- `GET /api/v1/tasks/{task}/dataset-preparation/preview/download`：当前候选完整JSON，权限与checkpoint一致。
- `GET /api/v1/projects/{project}/files/{file}/prepared-dataset-versions`及`/{id}`、`/{id}/rows`、`/{id}/download`：只读整理历史（列表5项、行20项），绑定原始source，保存规则可复制。

文件详情原始Sheet入口打开整理表单；显示区域和字段、两种操作，按钮“生成预览”。生成后显示实际差异和未解决项，提供“确认并生成版本”“修改规则后重新预览”；任务中心可在刷新/重启后继续。分析页面增加明确的原始/整理版本选择，历史结果标签来自已保存来源；中英文切换保留草稿。离开页面只保留当前待办，不新增取消语义。
