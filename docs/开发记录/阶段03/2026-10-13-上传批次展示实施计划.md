## 冻结响应与文案

新增字段属于 `FileMetadata`（分页items、details、purposes响应），不修改旧 `ProjectFile` 数组/上传响应合同：

```typescript
type UploadBatchSummary = {
  created_at: string; // 批次登记时间，UTC ISO8601
  item_count: number; // 此批次全部登记项数，1—10
  item_position: number; // 此文件登记ordinal + 1，1—10
};
// 后端始终明确返回对象或null；前端可接受旧响应省略字段。
type BatchMetadata = { upload_batch?: UploadBatchSummary | null };
```

中文：`上传批次：{date} · 本批登记 {count} 项 · 第 {position} 项`

英文：`Upload batch: {date} · {count} registered items · Item {position}`

空状态：`未记录上传批次` / `Upload batch not recorded`。

摘要只读取持久关系，查询同时限定项目和批次所属用户，并核对文件与上传项的双向关系。列表采用一条批量摘要查询或同等集合查询，不为每个文件单独访问批次；不顺带重构既有用途查询。
