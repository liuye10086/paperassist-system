## 合同与职责

`backend/app/domain/documents/ocr_contracts.py`只依赖Pydantic/标准库，可被Windows API读取，不初始化OCR运行时。Task1先落合同和`script/.runtime/stage03-step08/contracts.md`，通知后两任务。

```python
# Task1提供，函数签名固定。settings是OCR_SETTINGS精确快照；页选择独立保存。
parse_ocr(content: bytes, filename: str, file_type: str,
          page_numbers: list[int], settings: dict) -> OcrParseResult
parse_ocr_isolated(content, filename, file_type, page_numbers, settings,
                   *, on_started=None) -> OcrParseResult
# 顶层：document=OcrDocument，image_payloads={image_id:base64字符串}
# OcrDocument: schema_version=1,kind=ocr_document,filename,parser_version,
# source_type=pdf/png/jpeg,source_pages,selected_pages,pages,images,warnings,counts。
# OcrPage: page_number,width,height(识别像素),preview_image_id,rotation,
# source坐标/变换说明,text_status=text/no_text,text_blocks,warnings。
# OcrText: kind=ocr_text,id,text,score,review_status=unreviewed,
# polygon(识别像素四边形),source(page_number,原坐标/约定,label)。
# images复用Word Image基础元信息/独立二进制对象；不用旧PdfDocument装图片。
```

后端新增`POST /projects/{project}/files/{file}/document-versions/ocr`，请求`{expected_latest_version:int,page_numbers:int[]}`，沿用Idempotency-Key；图片页只能`[1]`。操作冻结原件版本/哈希、选择页、模型/配置；PDF OCR不依赖可变当前选中版本的内容，使用原件。`/document-versions`继续统一顺序版本，PDF旧重解析POST仍创建文本版本，图片旧重解析POST创建OCR版本。投影显式`kind`；OCR详情含图片下载信息，`/pages?page=N`返回所选页中的第N项但内容保留真实物理页码，`total`为本次所选页数。读取和下载校验原件/结果来源，原件不能被预览替代。

后端文件类型最小迁移`0020_ocr_parsing`：扩`files_type_check`为xlsx/docx/pdf/png/jpeg，同步metadata/head；结果和模型参数沿用严格JSON，不建新表。降级检查图片文件及OCR解析/任务历史，保留旧版本。
