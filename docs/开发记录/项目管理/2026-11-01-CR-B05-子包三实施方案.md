## 2 单细胞范围

### 2.1 输入与处理

1. 支持 Gene Expression 的 MTX+features/barcodes、10x H5，以及受控 H5AD 的 CSR/CSC counts、obs/var。H5AD 显式选 `X`、指定 layer 或 `raw.X`，分别核对其真实轴、有限非负整数值；整数值浮点存储可经验证转换并记录，不以 dtype 代替 counts 语义。dense H5AD、RDS、loom、多模态自动转换不在本包。
2. 复用 HDF5 受控读取与稀疏预算，白名单解析已支持结构；保留文件 SHA、成员/层、样本及特征轴和解析版本。只含标准化值时可登记或承接外部结果，不能执行原 counts 路径。
3. QC 使用每细胞 counts、检出基因数及明确线粒体规则，保留过滤原因和全部轴。单细胞不应用 `in_tissue`；同名 barcode 跨样本必须保留样本限定身份，不能混合。
4. 复用归一化/log1p、HVG、PCA、邻居图、UMAP、Leiden 和 marker，保留原 counts、处理层、实际参数与种子。marker 明确为数据驱动聚类后的探索结果，不重写已通过的统计核。
5. 支持非空间细胞群标签，保存 marker/图谱依据、决定人、版本及未知状态；不自动声称已验证细胞类型。缺供体映射仍可完成 QC/聚类/marker。
6. 对有真实 cell→sample→donor 映射及确认比较设计的输入，按指定细胞群聚合原 counts，接既有供体 pseudobulk 模型；保持配对/批次约束、独立供体 n 和缺失细胞群记录。无供体依据不执行供体推断，技术重复先按既有规则归并，不能按细胞数扩充 n。

### 2.2 产物与边界

完整导出 QC/过滤审计、细胞及特征轴、embedding、cluster、marker、标签证据、样本/供体计数及适用 pseudobulk 表；提供 QC、UMAP/PCA、marker 点图或热图和中文 Methods/报告。

不新增自动 doublet 去除、Harmony/scVI、轨迹/通讯、自动细胞类型鉴定。既有表达/QC图复用，不为本包再生成同一份原图。独立供体模型的数值核已通过则只补细胞聚合与来源桥接检查；真实供体推断验证仅在有合格材料时计入。

## 3 微生物组范围

### 3.1 输入、描述与推断

- 接收 feature×sample counts 或明确 fraction/percent 的 TSV/CSV/XLSX，配套 taxonomy 层级表与样本表。记录测量流程、分类数据库/版本、宿主和特征分类身份；不使用一个宿主物种代表全部微生物。
- counts 必须非负整数；相对丰度记录尺度与舍入容差，检查样本总和。需要重新闭合时显式记录操作与原总和，不静默修正负值、不明尺度或缺测值；全零样本及缺测样本进入审计和适用性判定。
- 分类聚合保留未分类项，按完整分类路径区分同名 taxon，核对每个样本聚合前后守恒。组成图的 Top N 加“其他”仅影响展示，完整丰度表不截断。
- 提供 Shannon（自然对数）、Simpson（明确为 `1−Σp²`）、Observed features（所给表中非零特征数，注明深度/过滤限制）；不从相对丰度推断绝对负荷或原测序深度。
- 固定相对丰度口径的 Bray–Curtis 距离及 PCoA，输出完整距离、坐标、特征值/解释比例及负特征值警告；全零/缺测的处理写入 Methods。
- alpha 多样性比较复用既有独立两组或完整配对方法。计划提前冻结指标、对比与 BH 检验族；不依据显著性选指标或方法。
- beta 推断限定独立、可交换样本的单因素 PERMANOVA，并同时报告 PERMDISP。默认 999 次置换、种子 0，参数冻结；PERMDISP 固定 median/eigh。配对、重复、分层或多因素设计不送入无限制置换，保留描述或外部结果入口。
- PERMANOVA 和 PERMDISP 分属组间结构检验与离散度诊断，分别记录目的，不因离散度结果而自动宣称组差异或因果成立。置换 P 值保留实际次数及有限分辨率。

### 3.2 产物与边界

完整导出输入/排除审计、taxonomy 聚合与守恒、组成、alpha、距离/排序、适用比较/校正及离散度表，提供组成图、alpha 样本图、PCoA 和中文交付。

不加入稀释、UniFrac/系统发育多样性、ANCOM/ALDEx2、绝对菌量、多因素或纵向置换；外部差异丰度结果继续用既有正式结果导入。

方法合同参考官方 [PERMANOVA](https://scikit.bio/docs/latest/generated/skbio.stats.distance.permanova.html) 与 [PERMDISP](https://scikit.bio/docs/latest/generated/skbio.stats.distance.permdisp.html)。方案阶段核对官方文档；实施固定 scikit-bio 0.7.4，旧 NumPy/SciPy 及其他原有依赖版本保持，兼容与新实际计算已验证。
