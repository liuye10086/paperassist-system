## 工作划分与合同

- [x] 后端文档生成退役：删除 PDF create/retry API、创建逻辑和转换执行；保留历史 owner-scoped GET/download、旧任务投影和固定包解析。新研究报告不接收 include_pdf_id，新交付不选择 pdf_export。从历史 PDF 服务抽出 Word 排版仍需使用的既有 DOCX 来源读取，不复制实现。移除新稿响应 pdf_status。保留历史迁移、数据库表和对象，不新增退役状态机。队列不得继续启动新 PDF 转换；已有未知/在途任务不取消、不重发、不改库。
- [x] 图件输出退役：删除新的图件配置 PDF 选项、默认 PDF 和实际保存分支，包括生信图、研究多面板、常规表格/科学子进程和复现代码中的新生成入口。保留历史 PDF 成员识别/数值或字节证明，不因此重算旧成果。研究图请求格式合同由后端文档任务统一修改，避免同文件并发。
- [x] 前端入口与提示：删除 PDF 生成组件、转换/重试入口、加入 PDF 新包选项及新图件 PDF 格式；保留已接手 GUI 改动、请求身份、草稿、审核门禁、下载鉴权和历史任务/成果展示。PDF 上传解析保留。GUI会话已解除相关文件编辑占用。
- [x] 共用字段服务：删除 render_pdf、/convert、UNO PDF 输出代码与对应纯转换测试；保留 /layout-cache、目录/页码字段计算、安全输入校验及本地隔离。历史服务/锁/字体配置的既有标识不做无收益全局改名。同步产品当前说明和需求变更记录，旧验收证据不倒改。

## 修改点 → 必要检查

1. 后端入口/合同 → 新 PDF POST 不存在或被拒绝且不建任务；DOCX 来源和字段仍可用；历史下载归属与冻结解析保持。用现有测试框架的最少代表节点验证，不建立全量新科学链。
2. 图件配置与执行 → PDF 新配置拒绝、默认输出无 PDF、实际保存路径无 PDF；保留 PNG/TIFF/SVG 代表检查，复用未变化的数值/科学证明。
3. 前端 → 受影响导出与图件选择定向组件测试、一次 TypeScript 检查和隔离构建。不重跑 GUI 405 项、旧科学链或 Word 页检。
4. 字段服务 → /convert 拒绝、/layout-cache 保留的离线 transport/server 检查；已有 Word 成品不重导。静态编译/导入与链接/差异检查。

具体文件归属、定向日志、移除清单与残留 PDF 分类记录在 `script/.runtime/client-requirements-docx-only`。最终做一次本次增量审查，不以整个脏工作区相对 HEAD 的差异重审 B05/W1—W4/GUI。
