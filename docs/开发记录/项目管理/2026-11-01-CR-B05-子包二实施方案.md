## 3 qPCR 输入与计算合同

### 3.1 输入、审核与版本

CSV/TSV/XLSX 长表，显式指定工作表、列和原件/解析版本。必要角色：`plate_id, well, sample_id, biological_unit_id, target_id, cq, detection_status, technical_replicate, condition`。配对/时间/剂量及其单位按设计指定，不从文件名猜。

另冻结：靶标/内参名单、内参适用性依据、校准组或样本、方法、效率及来源、跨板可比依据、纳入/排除规则、预设对比与校正族。没有板位资料时只能先登记或核对汇总，不能完成逐孔完整验收，也不能生成虚构板位冒充原始实验记录。

- 逐孔保留原文本、解析值、行/单元格位置、纳入状态和理由。未检出/空值保持NA及检测状态，不替成0或最大循环数。
- 板位冲突、样本角色不一致、重复个体/时间记录等，在依赖的计算前阻断；不一并阻断其他无关输入。
- 先按样本×靶标×板汇总已纳入技术孔，输出有效孔数、均值、SD及缺失/排除数。异常值仅提示，必须显式确认排除；技术孔不增加生物学n。
- 跨板无可比依据时分板计算，禁止合并为跨板结论；同一生物学单位换板仍不是新增独立样本。

### 3.2 两种显式方法

**等效率 ΔΔCq**：只有具备适用性依据并确认后才执行。先对各assay的技术孔取均值，再对多个内参取等权Cq均值：

```text
ΔCq_sample = mean_Cq_target − mean(mean_Cq_each_reference)
ΔΔCq_sample = ΔCq_sample − mean_ΔCq_calibrator
relative_quantity = 2^(−ΔΔCq_sample)
```

**给定效率的相对定量**：每个assay提供有限且大于1的扩增因子及测定来源；`E=1+efficiency`，100%效率对应2。冻结输入表示和换算，不能把百分数100直接当E。

```text
R_sample = E_target^(Cq_target_calibrator − Cq_target_sample)
           / geometric_mean(E_ref_j^(Cq_ref_j_calibrator − Cq_ref_j_sample))
```

校准组先按生物学样本等权汇总，不按技术孔数量加权；内参/校准缺失时明确给出不可计算原因，不静默改用剩余内参。效率合理性检查与用户依据一并记录，不猜效率或静默截断异常值。

效率校正参考[Pfaffl原始方法](https://pmc.ncbi.nlm.nih.gov/articles/PMC55695/)；实验与报告元数据沿用[MIQE 2.0](https://doi.org/10.1093/clinchem/hvaf043)作为方法依据，不将软件检查等同于实验质量认证。

### 3.3 推断、方向和原表核对

- qPCR本轮支持预设的独立两组或完整配对比较，调用现有统计内核。多条件只能执行事先定义的二组对比，不自动穷举。
- 检验在生物学样本的ΔCq或效率校正log量上进行；明确“ΔCq处理减对照为正表示相对表达较低”，不与log倍数变化的正方向混用。
- 靶标×对比的检验族在计算前冻结，保留原P、BH校正值、实际n、配对数与NA原因，不用只筛出的显著靶标重新定义校正族。
- 图显示实际生物学样本点、适用的配对线及明确的SD/CI类型。以log尺度组间效应和区间反变换显示倍数变化；区间端点正确转换，不能给倍数值机械加对称误差线。方法不提供CI时保留NA及原因。
- 原报告核对另存 `original_value / recomputed_value / difference / tolerance / decision`。容差按报告精度和数值误差来源预先确定；单位/方向错误不能靠放大容差消除。原报告与重算结果都不被覆盖。

输出正式成员：逐孔审计、技术汇总、参考/校准配置、逐生物样本数量、完整检验/校正族、排除及缺失原因、原报告差异、完整图数据、Methods与复现清单。
