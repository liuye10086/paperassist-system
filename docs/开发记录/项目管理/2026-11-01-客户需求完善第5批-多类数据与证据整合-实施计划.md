## 3 方案选择、顺序与共同设计

### 3.1 选择

推荐“**四个完整子包，扩展现有服务**”。它复用最多，也使每个子包都能单独验收。一次九类同时改完再验收，会使输入、方法和来源问题难以归因；全部仅导入外部结果虽快，但不能满足单细胞、qPCR、序列实际提取等要求。后两种不作为推荐实施路径。

执行顺序：**子包一 → 子包二 → 子包三 → 子包四**。子包一落地必要的非空间输入、尺度和来源适配；子包二补实验计算及旧统计来源；子包三使用同一基础支持细胞/群落；子包四使用已冻结的成果进行跨数据关联。四包各有自己的导出和验收记录，后包不改写前包历史快照。

### 3.2 输入和方法合同

新增能力统一冻结以下信息，但使用各自具体 Pydantic 合同，不把任意 JSON 当可执行配置：

| 合同部分 | 必需信息及规则 |
| --- | --- |
| 原件 | `file_id`、`parse_version_id`（适用时）、SHA、sheet/member、列映射；不接受客户端任意路径/URL作为已取得数据 |
| 数据类型与尺度 | `assay`、`observation_level`、`feature_namespace`、物种/参考版本、`measurement_scale`、单位、已有变换/标准化；未知尺度可保存，但阻断依赖尺度的计算 |
| 轴及重复 | 稳定 `feature_id`、`observation_id`；sample/donor/pair/time/plate/well 分列；技术重复与独立重复明确分开，不假造 barcode 或 spot |
| 处理 | 过滤、缺失、零值、转换、标准化、异常排除的规则与理由；保存处理前后数量、原值和派生层 |
| 方法 | 配方/算法版本、明确参数、随机种子、比较组/参照组、设计列、比较族、校正范围；不自动换方法或根据结果挑方法 |
| 来源 | 原始客户/公共再分析/外部结果/手工转录/本地提取分别标记；相同源数据的不同格式不增加独立证据 |
| 运行 | 沿用 task/run/attempt/checkpoint/lease、资源合同、代码/环境摘要、幂等键和源摘要 |

普通 CSV/TSV/XLSX 继续沿用当前表解析上限：10 MiB、100000 行、256 列、1000000 单元格，不把大矩阵包装为普通表绕过。稀疏格式走版本化矩阵导入；超限真实输入先给容量建议，不截断、抽样冒充全量或修改全局上限。

## 5 子包二：qPCR 与表型、行为、临床表

### 5.1 qPCR计算合同

CSV/TSV/XLSX 长表至少明确 `plate_id/well/sample_id/biological_unit_id/target_id/cq/detection_status/technical_replicate/condition`；适用时带 pair、time、dose。另冻结靶标/内参、参考基因适用性证据、校准组/样本、效率、跨板校准及排除规则。板位重复、单位冲突作为输入问题；未检出保留 NA 和状态，不变成0或最大循环数。

按样本×靶标×板汇总已纳入技术重复：保留每孔原值、有效孔数、均值/SD、排除理由。仅提示异常候选，不自动删除。跨板没有可比依据时分板计算，阻断受影响的跨板结论。

支持两种显式选择的方法：

1. **等效率 ΔΔCq**：只在有适用性依据并明确确认时使用。`ΔCq = mean_Cq_target - mean(mean_Cq_each_reference)`；`ΔΔCq = ΔCq_sample - mean_ΔCq_calibrator`；`relative_quantity = 2^(-ΔΔCq)`。多个内参的等权Cq均值对应其相对量的几何均值，不能混用任意平均规则。
2. **给定效率的相对定量**：每个assay明确扩增因子 `E=1+efficiency`，例如100%效率对应2；`R = E_target^(Cq_target_calibrator - Cq_target_sample) / geometric_mean(E_ref_j^(Cq_ref_j_calibrator - Cq_ref_j_sample))`。校准组各assay的Cq先按生物学样本等权汇总，不按技术孔数加权。保存输入效率及其测定来源；不从未知值猜E，也不在本批新增原始荧光曲线拟合。

组间检验在独立生物学样本的 ΔCq 或效率校正后的log量上进行，明确正负方向；技术孔不增加n。独立/配对方法复用现有统计并预声明靶标×对比校正族。展示样本点、配对线及明确尺度的汇总/区间；由log尺度转换的区间是非对称区间，不对倍数结果机械加对称误差线。

输出逐孔审计、技术汇总、内参/校准、样本ΔCq/ΔΔCq/相对量、全检验/NA原因、原表值与重算值/差异/容差。容差按原报告精度冻结，不能以四舍五入掩盖方向或单位错误。效率与内参原则参考 [Pfaffl原始方法](https://pmc.ncbi.nlm.nih.gov/articles/PMC55695/) 和 [MIQE 2.0](https://academic.oup.com/clinchem/article/71/6/634/8119148)。

### 5.2 表型、行为与临床范围

## 6 子包三：单细胞与微生物组

### 6.1 单细胞

支持 Gene Expression 的 MTX+features/barcodes、10x H5，以及受控 H5AD 的 CSR/CSC 非负整数counts层、obs/var。H5AD必须显式选择counts位于 `X`、指定layer或raw，并核对真实值和轴；只读白名单数据结构，不加载pickle或任意代码对象。只有归一化矩阵时可登记、导入既有结果；不伪称原counts流程可执行。Seurat RDS、loom、CITE/ATAC多模态及自动格式转换本轮不承诺。

复用 B02 组件完成每细胞counts/基因数/线粒体比例、过滤、独立归一化/log层、HVG、PCA、邻居图、UMAP、固定种子聚类及marker。线粒体标记、过滤、分辨率、种子均显式冻结；不自动套用空间 `in_tissue` 条件。输出每步保留/排除细胞和特征。聚类算法优先沿用已安装、已支持的实现，名称/参数在预览中明确，不无声换用其他算法。

marker为数据驱动聚类下的探索证据；复用已有经对照的marker核，不因接单细胞重写相同统计。细胞类型标签保存marker/图谱依据、决定人和未确定状态；不自动命名为已验证类型。带真实独立供体和cell→sample→donor映射时，按确认细胞群聚合原counts接B04供体模型；无供体不阻断QC/聚类，只阻断供体推断。双细胞/批次问题展示诊断和外部注释，自动doublet去除、Harmony/scVI、轨迹/通讯不自动加入。

输出QC、embedding、clusters、marker全表、细胞/供体计数、注释证据、适用pseudobulk，及QC/UMAP/PCA/marker点图或热图。Scanpy输入及marker约定参考 [1.11文档](https://scanpy.readthedocs.io/en/1.11.x/generated/scanpy.tl.rank_genes_groups.html)，不依据latest接口改变当前1.11.5版本。

### 6.2 微生物组

支持 feature×sample counts或明确fraction/percent相对丰度，加分类层级表和样本表；记录16S/宏基因组等测量流程、分类数据库/版本及已有过滤。微生物群落不强制填写一个宿主物种冒充每个feature物种；宿主与taxon ID分别保存。分类聚合输出未分类项及守恒对账，不丢弃未注释丰度。

建议范围：组成图；Shannon、Simpson、Observed features（明确counts/深度限制）；Bray–Curtis距离、PCoA；alpha多样性适用独立/配对比较；独立样本单因素 PERMANOVA 与 PERMDISP。计数先按明确方案转相对丰度用于选定距离，原counts保留；fraction/percent严格识别并记录允许的舍入误差，不静默归一化任意负值或不明尺度。

无放回稀释、系统发育多样性/UniFrac、ANCOM/ALDEx2、绝对微生物负荷及纵向/分层置换不在首期默认范围；丰度差异结果可走B04正式外部结果导入。只有相对丰度时不推断绝对菌量；零丰度、未测与未分类分开。单因素PERMANOVA只用于可交换的独立样本；配对/重复数据不直接调用无限制置换。输出pseudo-F、P、置换数/种子、距离与离散度结果，不把组间差异自动解释为某菌导致疾病。

距离/置换采用成熟库，具体合同参考 [PERMANOVA](https://scikit.bio/docs/latest/generated/skbio.stats.distance.permanova.html)、[PERMDISP](https://scikit.bio/docs/latest/generated/skbio.stats.distance.permdisp.html)。PCoA记录负特征值及警告，不能隐藏明显非欧氏失真；两组计算相同距离但不同排序符号不误报为科学结果不同。

## 7 子包四：序列/结构、多组学与外部证据

### 7.1 序列/结构实际提取

推荐同时提供注释导入和下列有限本地提取，不把导入记录算作提取完成：

| 输入 | 实际计算范围 | 明确边界 |
| --- | --- | --- |
| DNA/RNA FASTA | 稳定序列ID、总长、有效碱基/歧义比例、GC比例；GC分母明确为A/C/G/T(U)，全未知返回NA | 不推断功能、ORF、变异致病性或自动比对 |
| 蛋白 FASTA | 长度、标准20种氨基酸组成和未知/终止符记录 | 不预测结构、信号肽或功能域；不把未知字符删去后悄悄改变长度 |
| PDB/mmCIF | 明确model/chain的观测残基数、原子数、Cα几何质心/回转半径；替代构象按明确occupancy规则、并列时固定规则且留痕 | 是已提供坐标的描述特征，不是三维预测/对接/结合能；不把B因子自动当pLDDT；缺坐标不当作序列真实缺失 |

使用Biopython解析，保留解析告警/拒绝项；不通过宽松解析静默丢原子。参考 [序列工具](https://biopython.org/docs/latest/api/Bio.SeqUtils.html)、[PDB/mmCIF文档](https://biopython.org/docs/latest/Tutorial/chapter_pdb.html)。表中几何特征以固定公式计算并作手算对照；工具版本、输入SHA、对象位置、参数及规则进入Methods。特征表接B04候选筛选，输出分布/散点图、筛选步骤和完整保留/排除清单。

### 7.2 多组学整合

先冻结两种对应资源：样本对应表 `(dataset_version, observation_id, donor_id, tissue, time, match_group, relationship)`，对象对应表 `(source_namespace/id, target_namespace/id, relation, version, evidence, ambiguity)`。相同样本、同个体不同组织、独立实验、部分对应分别表示。源数据的重复表示先按canonical lineage识别，不能增加证据数。

- **相关**：相同或明确配对单位的固定定量层，选择预声明特征/候选集合做Pearson/Spearman；输出每对完整样本ID、n、相关系数、P、BH和缺失原因。至少3对只是数值可计算条件，不表示有充分科学效能。重复个体不按多行独立计算；不同组织标明跨组织探索。固定校正族后不能按P值先筛再校正。
- **通路与一致性**：复用B04有版本背景/映射/基因集的结果，按对象和比较方向生成支持、冲突、无差异、未知、不可比较矩阵。不同组学的effect单位不能直接相加；一对多ID映射明确展开/排除规则和去重计数。
- **网络**：仅从已核定相关、对象映射、通路成员关系和证据关系生成节点/边表，边标注类型、来源、方向含义、权重及核验状态。相关边是关联，不能渲染成因果箭头；外部作用方向只有原来源明确时才显示。

初始限10个数据来源、10000对预声明特征关系；网络展示最多200节点/1000边，用户确认的展示过滤写入配置，完整受检关系仍导出。不默认全基因两两扫描、不新增多组学潜变量/深度整合或机制推断算法。流程图从固定处理谱系产生，网络布局种子冻结，改色/排版不重算统计。

### 7.3 外部证据

复用外部资料和文献服务，为疾病文献、表达图谱、公共验证、敲除/突变记录增加具体字段：证据类型、稳定对象/变异ID、物种、组织/细胞、条件/处理、测量尺度、参考版本、出处及原文/表/页定位、取得日期、许可、队列/供体重叠与独立性状态。

疾病范围、直接疾病与后代类别分开；人/鼠和不同组织不能自动互认。敲除/突变保留实验条件和原文结论，不自动跨条件写因果。来源未提及不等于阴性证据；未知不赋零分。同一数据集重分析、同一研究不同格式/论文重复报道不计独立验证；不同accession也须核对共享受试者。

公共验证必须有独立材料和设计、真实分析run、结果及来源关系才能标记“独立数据支持”；仅有下载/引用/图谱条目不能升级。真实联网检索/API/下载按冻结来源与许可清单另获相应授权，科学计算进程仍禁止外网。当前本地未具备的证据显示待补，不全局阻断。

输出候选×证据全表、冲突/缺失项、证据矩阵图、来源网络/流程图、Methods、完整报告/成果包，并送既有研究发现。默认规则排序；只有明确权重和口径时使用B04已有加权模式，不新增“综合可信度”分数。
