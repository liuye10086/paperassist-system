- 在 `BioLimits` 集中登记 Bulk 容量边界：单个 tabular 文件 128 MiB、展开预算 256 MiB、Bulk 矩阵 5,000,000 单元格、Bulk 样本列 512；部署覆盖只能收紧这些上限。

- Bulk 合同支持 512 样本列并保留样本集合、重复列和非 Bulk 样本上限校验；既有特征上限和数据安全校验保留。
- Worker 镜像增加 `requirements-bio-insights.lock.txt` 固定解释器 `/opt/paperassist-bio-insights`，并将 insights runtime manifest、独立 staging 目录加入 `compose.workers.yml` 与 `script/dev/worker_stack.py` 的准备、指纹和挂载流程。
- insights sandbox 的输入成员、CPU、地址空间、文件大小和展开预算改为从已登记限制读取；runtime probe 收据同时记录并校验 Bulk 限制，容量变更会使旧收据失效，要求重新探针。
