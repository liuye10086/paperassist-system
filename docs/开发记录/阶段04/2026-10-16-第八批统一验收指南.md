## 3. 任务错误与可采取动作

打开任务详情；若已有相应异常任务，核对下表。不存在该异常时，不必故意制造或付费触发，直接查看本批隔离测试截图/回执作为开发证据。

| 情况 | 应看到的行为 |
| --- | --- |
| 输入/规模限制 | 分清描述100000值、建模最多10000行、20展开效应、8MiB输入；空输入是样本不足。不会自动删数据。 |
| 输出损坏/缺失/过大 | 提示未发布结果并检查执行环境或输出规模，不一律要求删行或改协变量。 |
| 预算等待 | 核对用量，管理员按实际需要调整后继续原任务；不会清空用量、重发已提交调用或自动更换计划。验收不要求调整真实预算。 |
| 提交结果未知 | 明确联系管理员核对已有请求和费用；没有“重试原任务/继续原任务”按钮。不能把未知消耗当成功或零费用。 |
| 来源/核对失败 | 保留失败原因，不能沿用错误结果生成下游；修订时仍需独立确认来源/计划。 |
