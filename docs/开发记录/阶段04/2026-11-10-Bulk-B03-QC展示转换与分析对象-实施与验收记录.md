B03 在 B02 固定的 Bulk raw-counts、样本映射和研究设计输入上完成样本/特征 QC、过滤记录、展示层转换、PCA、样本聚类、相关/距离热图、组别/批次标注、便携式分析对象和疑似异常样本人工复核入口。B03 不实施 B04 的模型确认、差异表达或通路分析。

## 2. 已实施内容

### 2.1 QC 和过滤记录

- `sample_qc` 记录 `total_counts`、`detected_features`、`zero_fraction`、缺失数、表达分布五数摘要、condition、batch、donor、生物学单位、保留状态和排除原因。
- `feature_qc` 记录缺失、检测样本数、零比例、保留状态和排除原因。
- manifest 写入 `filter_rules`，明确样本/特征只接受 recipe 中的显式人工排除，`automatic_exclusion=false`；不会根据聚类或距离自动删除样本。
- 对 Bulk counts 的文库大小使用 robust z 提示疑似异常样本，提示包含依据但不改变 observation mask。人工排除通过已有 `exclude_samples` 保存新 recipe 版本，原始结果和 raw counts 保留。
- 新增表达分布图件，并保留图数据、PNG/TIFF/SVG 及固定图件 manifest。

### 2.2 展示层和分析对象

- 保留完整 raw 层和 `raw_axes/raw_values`；同时保存过滤后 counts、normalized counts、VST 和现有 analysis/display 层。每层都记录值成员、缺失成员、形状、轴语义和尺度；非 Bulk assay 不生成或暴露 VST 层。
- Bulk VST 使用明确公式 `2 * sqrt(normalized_counts + 3/8)`，仅接受 Bulk raw counts；VST 是独立展示层，不替换 raw counts，也不作为 B04 差异模型确认。
- 保存 `analysis_object.npz` 与 `analysis_object_manifest.json`，格式为 `paperassist_tabular_analysis_object_npz_v1`。对象中的 raw/filtered/normalized/vst 对齐过滤后的分析轴，完整原始轴由 raw 层和 `raw_axes` 独立保留；对象清单记录 `params`、`setup_id`/recipe identity、代码和环境 identity digest，并明确 `raw_axis=filtered_analysis` 与完整 raw 成员引用；生成后和父级产物校验都会执行 loader roundtrip。
- 增加 `sample_correlation`、`sample_distance` 数据和对应相关性/距离热图；complete feature、Pearson correlation、Euclidean distance、实际 layer/semantic 和 condition/batch 标签写入图数据。PCA 与聚类图数据也保留 condition/batch 数组及实际 analysis 层语义。
- PCA 继续只使用完整且非恒定特征，不使用 DEG 预筛；解释方差、scores、loadings、聚类 linkage 与选择原因均保留。低样本或不可计算时写明原因，不伪造结果。
- API 有界矩阵预览扩展支持 `raw`、`filtered`、`normalized`、`vst`，并保留 `analysis/display` 兼容入口。

### 2.3 前端审阅和人工复核

- `BulkQcDetails` 展示总计数、检测特征数、零比例、表达分布、raw/filtered/normalized/VST 层语义和分析对象往返状态。
- QC 结果页显示表达分布、相关性热图和距离热图；PCA/聚类页面继续显示已有图件和结果表。
- 疑似异常样本区域明确显示“仅提示，不自动排除”，提供“进入人工排除”入口回到分析配置页保存新 recipe。VST 选择会自动清除冲突的数值变换，并给出独立展示层说明。
- 新增 B03 中英文界面词条，保留旧结果页和其他 assay 的兼容行为。

## 4. 变更和修复记录

- 首轮 B03 数值测试发现 manifest 在 `layers` 填充前读取 `layers['analysis']`，造成 3 项失败；修复构造顺序后 64 项数值组合通过。
- 首轮 API 逐层预览发现路由参数仍只接受旧的 `analysis/display`；扩展 API 合同并复跑 foundation，4 项通过。
- analysis object 初版曾把全 raw 轴与过滤轴混写；现已统一对象内部使用过滤后分析轴，并把完整 raw 轴留在独立 raw members 中；对象清单补充参数、来源 identity digest 和轴引用，生成及父级验证均执行 loader roundtrip。
- 非 Bulk assay 初版会产生重复的 VST 层；现已限制为 Bulk raw counts，其他 assay 的矩阵预览和对象不再暴露 VST。
- 结果 source 初版缺少 owning `setup_id`；现已从冻结 manifest identity 投影到 `BioProcessedDatasetSourceV2`，旧结果缺失时人工排除入口保持禁用。
- 前端兼容后端两种异常提示结构：`reasons[]` 或 `advisory/basis`，不因异常样本提示结构差异崩溃。

## 5. 用户验收边界

建议按以下流程验收：

1. 打开 Bulk 结果的 QC 页，核对总计数、检测特征数、零比例、表达分布和 condition/batch 信息。
2. 分别读取 raw、filtered、normalized、VST 四层有界预览，核对层标签、轴和原始 counts 未被覆盖。
3. 查看 PCA、样本聚类、相关性热图和距离热图，核对解释方差、样本 ID、组别/批次标注以及不可计算原因。
4. 在疑似异常样本提示中进入人工排除，保存新 recipe；确认原始结果和 raw counts 仍可访问，且聚类没有自动删样本。
5. 查看分析对象格式和往返状态，确认对象轴、参数和来源版本在结果清单中可追溯。

以下事项不计入本批通过：

- 真实用户文件、真实生物学验证、60,000 × 50 实际分析及性能/RSS/磁盘/取消记录。
- B04 模型确认、差异表达、A vs B/B vs A 统计方向和后续通路分析。
- 不把 QC 提示、PCA/聚类或分析对象往返当作生物学独立重复或科学结论验证。
