## 1. 实现与统计口径

| 入口 | 实际行为 |
|---|---|
| Bulk 多比较查询 | 从已审阅的 `bulk_counts` / `shared_wald_v1` 固定结果读取。切换 contrast 时显示 numerator、denominator 和对应计数。完整表、DEG、上调、下调分别查询。使用精确稳定 ID 跨比较定位同一基因，分页和查询保留完整表下载及全比较计数。 |
| 统计口径 | 比较内 BH `q_within_contrast`、跨比较族 BH `q_global_family` 和方法原生 `original_method_adjustment` 独立展示。默认 q ≤ 0.05、｜MLE log2FC｜≥ 1，支持调整和方向筛选。保留过滤、不可计算、所选统计量缺失及原始零值。 |
| 候选与 Top N | 按所选 q 升序、绝对效应降序、稳定 ID 升序冻结候选。完整候选、独立 Top N、选择参数和来源行证据一并发布。空集合可发布，不足 N 显示实际数量。父进程独立对账完整集合、顺序和来源。 |
| 差异与表达图 | 火山图和 MA 保留全部可绘制点及完整行数据，Top N 约束标注。DEG 热图沿用显著性排序，高变热图按固定模型归一化 counts 的样本方差排序并以稳定 ID 打破并列。候选表达和热图使用所选比较的固定样本轴及归一化 counts。热图可按行 z-score，记录测量数、均值、样本标准差及不可转换原因。数量汇总保留各分类和对应行。 |
| QC 与 PCA 重绘 | 缺失比例、样本表达五数摘要、聚类、相关与距离，以及 PCA 得分和解释方差都读取 B03 固定成员。样本条件与批次一起保存。图标题、配色、尺寸、DPI、Top N 和格式随新版本记录。 |
| 已有富集图 | 可选用调整指标、稳定 term ID、原行键排序并显示实际 Top N，点图可使用指定配色。历史图件继续沿用原有设置。B05 的验证对象为已保存富集表的排序和绘图。 |

图件发布包含 PNG、TIFF、SVG 中所选格式和完整 `plot_data.json`。任务使用固定 worker 的 `bulk_display` 收据，验证来源成员和冻结参数；`bulk_model` 保持独立准入。

## 2. 固定公开数据与 Edge 验收

复用 [B04 验收记录](2026-11-10-Bulk-B04-模型确认与差异表达-实施与验收记录.md) 中的 Bioconductor `airway` 固定数据和隔离 PostgreSQL 测试库。8 个样本来自 4 个完整供者配对，每个方向 64,102 行。B04 差异版本为 `b8c84019-c8fe-5afa-b052-b303eddaa285`，B03 处理版本为 `e39f31ac-9fba-5e6a-91c1-cecf4d326103`。双向 128,204 行差异表的 SHA-256 为 `d270734ea77b38620269eeb538b26979c09a3316de4d1c8aa9db9f94a588f74d`。

- Edge 切换 `Dex_vs_Untreated` 和 `Untreated_vs_Dex`，核对比较标签、默认筛选及完整表。默认比较内 q 在正向得到 1,025 个 DEG（上调 536、下调 489），反向上、下调数量互换。正向改用原生调整值，得到 1,051 个 DEG（上调 544、下调 507），4,323 行缺失该调整值。
- 输入 `ENSG00000000003` 跨比较查询，双向效应约为 −0.38118148 和 +0.38118148，p、q 一致。将效应阈值提至 1,000,000，DEG 为 0，完整表仍保留 64,102 行。
- 从 Edge 提交火山图、候选、PCA 得分图和火山图样式新版本，经隔离 RabbitMQ、固定 Docker worker、父进程对账并从任务页打开已发布结果。候选页面可在独立 Top 20 和完整 1,025 项之间切换，完整表支持翻页。

## 4. 验收边界

- 本批的实际发布与下载使用公开 `airway` 的固定结果。真实用户数据、60,000 × 50 大矩阵的容量与性能、同一数据的独立 R DESeq2 全量对照待后续验证。
- QC 表达图沿用 B03 固定的 raw counts 五数摘要。个别大值会压缩线性坐标上的四分位区间。下载数据保留原值。离线重绘需要与清单匹配的固定解释器和依赖。
- B05 的富集验证覆盖已有结果的排序与绘图。Bulk ORA/GSEA 实算和本地注释资源属于 B06，连续交付与 Word 属于 B07。
