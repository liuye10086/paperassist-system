## 1. 建立不做清理的父版本

进入用于验收的项目，上传主样本，待解析和结构提取完成。选择工作表 **`研究 & 数据`**，进入原始“整理数据”入口：表头行 **1**，数据区域 **`A2:C11`**，字段依次为 **X、Y、Group**。

点击“读取建议字段”，确认字段名称。此合成样本没有测量单位，可勾选“确认单位 A/B/C”并将单位留空，表示已确认无单位。三列均保持**不去除首尾空白、不启用缺失标记**。生成预览并确认发布，得到含10条记录的首次整理版本。

首次整理版本通常显示为整理数据v1；后续质量版本通常为v2。请以页面实际版本序号为准，版本序号与内部合同版本是不同概念。后面的“父版本”均指此处明确选择的首次整理版本。

## 2. 按父版本处理质量问题

在“整理版本历史”或“字段详细概况”点击该父版本的“按此版本处理质量问题”。核对页面锁定直接父版本、区域和字段；重复值默认保留，缺失值不填补，IQR只提示异常候选。

按下面设置本轮策略：

| 设置 | 本次选择 |
| --- | --- |
| A列X | 开启去除首尾空白；启用缺失标记，填入精确标记 `NA` |
| B列Y、C列Group | 保持字段清理关闭 |
| 手选全行排除 | 勾选Excel源行 **9、11**，不是数据列表中的第9/11条 |
| 源行9理由示例 | `合成验收：排除源行9，核对先手选后去重。` |
| 源行11理由示例 | `合成验收：排除源行11，核对人工理由与回执保留。` |
| 重复值策略 | 选择“全部字段精确去重” |

先勾选一行且不填理由，核对“生成质量预览”不可用；填写理由后再继续。理由作为用户声明原样保存。切换一次中英文界面，核对系统提示翻译而字段名、工作表名、`NA`及自填理由不被改写。

## 3. 核对完整影响，再确认发布

点击“生成质量预览”。以下是主样本在上述确切规则下的预期：

| 核对项 | 预期 |
| --- | --- |
| 原始选定区域 / 直接父版本记录数 | 10 / 10 |
| 继承排除 / 本轮手选排除 / 本轮重复排除 | 0 / 2 / 1 |
| 累计整理排除 / 当前整理保留 | 3 / 7，即 **10 − 3 = 7** |
| 变化单元格 | **1格：A5**，先修剪再标记缺失，只计一格 |
| 完整影响条目 | **4项**：两项手选排除、一项单元格变化、一项重复排除 |
| 最终保留的源行 | **2、3、5、6、7、8、10** |

核对重复排除的是源行4，保留源行3；手选源行9后，其重复组中的源行7仍保留。**源行7的X=1000仍应存在**：异常候选不自动删除。

在影响明细中分别查看手选、单元格变化和重复排除；点击源坐标，核对直接父版本原行。按操作筛选，并用自己填写的一条完整理由做精确筛选。下载“完整质量回执”，核对四项影响、前后值或父记录引用、保留源行及两条原样理由。

点击“修改规则”，确认旧预览不再提供“确认并发布”；保持或重新填好本轮规则，点击“重新生成预览”，再次核对汇总和回执后才确认发布。等待任务显示“已完成”；完成后不应继续出现“离开页面后任务仍等待确认”的提示。新版本应单独出现在历史中，父版本仍可查看和下载。

## 4. 分别确认两个分析计划，核对各自有效n

在分析配置中明确选择刚发布的质量版本。质量确认不会自动发布分析计划；每个候选计划仍须检查并单独点击“确认并发布分析计划”。

本次只做软件流程验收。研究资料可明确填写为：研究人群“本文件中的人工构造记录，不代表真实人群”，研究设计“合成数据功能验收”，观察单位“每一源行是一条合成观察”，配对或重复测量关系“本用例未设置配对或重复测量”。研究问题分别写明“描述当前保留合成记录的X分布”与“核对当前保留合成记录中X/Y共同完整记录的Pearson分析流程”。这些是用户为本用例填写的声明，不是程序从数据中推断出的真实研究设计。

| 计划 | 选择及预期 |
| --- | --- |
| 描述统计 | 选择X，不分组。当前整理保留7条，本分析因X缺失排除1条，**n=6**。有效X为10、20、40、1000、50、60，合计1180，均值约**196.6667**。界面显示6位有效数字时可显示**196.667**；合计用于手算核对，不要求结果表另有“合计”列。 |
| Pearson单对相关 | 选择X、Y。共同完整记录为源行**2、3、7、8、10**，本分析排除2条，**n=5**。必须另行审核并确认该计划；它与描述统计使用同一质量版本，但有效n不同。 |

Pearson的独立观察、关系形态和双侧推断前提须由用户明确核对并声明，不能让系统猜测或因质量处理完成而自动勾选。本样本故意包含极端值，仅供软件验收；若不确认某项前提，保留未确认并核对计划阻断即可，不把合成样本的P值作为科研结论。

核对结果页的两级数量：先显示上游“原始10 − 整理排除3 = 保留7”，再显示本分析的“7 − 1 = 6”或“7 − 2 = 5”。不能把整理排除再次扣除，也不能把当前7条称为原始10条。切换结果或查看历史已确认结果时，每个结果应保留自身计划、来源、语言和有效n。

## 5. 核对45项完整影响分页

另行上传“45条影响分页样本”，先通过原始整理入口发布一个不修剪、不标记缺失的父版本。再从该父版本进入质量处理：**只开启A列去除首尾空白，重复值保留，不手选排除**。

生成预览后，完整影响应为45项，三页依次显示 **20 / 20 / 5** 项。核对下一页、上一页和坐标定位，下载回执应包含全部45项，而不是当前页或前20项。修改规则后重新生成的预览应重新开始核对，不能继续确认旧预览。

若要核对跨页手选，可另开草稿，在第一页和第二页各选一行并填理由，再返回第一页确认选择仍在；该草稿与上面的45项基准任务分别保留，避免把额外手选混入基准数量。

## 6. 核对同父重新进入与0行阻断

回到主样本的首次整理版本，在完成一次质量任务后，再次点击同一版本的“按此版本处理质量问题”。应出现新的策略草稿和“生成质量预览”，不应停在上一次的完成回执；单击入口本身不会自动发布或提交新的任务。可分别从整理历史与字段概况入口各核对一次。

使用一个独立草稿测试0行边界：从主样本首次整理版本选择源行2至11全部10行，每行填写合成验收理由，保持其他规则关闭并生成预览。应显示当前保留0条、明确阻断发布，同时仍能查看预览、下载回执和修改规则。保留该草稿即可；不需要删除任务或覆盖已有版本。

恢复先前排除的行，应从仍含该行的更早版本另行派生。直接在已排除版本上把去重改成“保留”，或关闭修剪/缺失标记，只会停止本轮新增处理，不会恢复父版本已排除的行或已修改的值。

## 7. 核对图表计算、本地报告与历史成果

可选择当前质量版本做一次本地图表计算检查，例如Group计数柱状图。这里只核对投影保留范围与数量，不必发起云端生成：绘图投影不能重新纳入上游已排除的源行，投影记录数与各统计计划的有效n须分别标明。

报告集合继续要求同一整理版本、工作表和语言；即使原始文件相同，也不能混入不同整理版本的结果。展开“九类报告内容预览”，核对处理策略、用户理由、前后质量概况及**10 − 3 = 7**，并从该版本的“下载完整质量回执”取得完整明细。统计章节应将7条称为“整理后保留记录数”，逐计划保留n=6或n=5；页面不显示内部UUID、哈希、资产路径或规则代号作为说明。

若该确切来源已有齐备的图表与解释，可沿既有入口本地整理Word，核对冻结的处理摘要、理由、统计有效n，以及“整理阶段”与“统计阶段”清理说明。若缺少同源图或解释，核对集合预览和明确的等待状态即可，**本轮验收不要求为补齐报告新增付费调用**。本地整理集合不会自行发起收费绘图或解释。

同时打开一份已有历史成果或报告，核对原来源、内容及下载仍可用；旧整理v1缺少完整质量明细时，应说明“旧版本未记录”，不能显示成“确认处理为0”，也不能用本批结果重写旧快照。
