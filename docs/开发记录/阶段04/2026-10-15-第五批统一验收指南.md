## 九种图的核对重点

| 图型 | 操作及应观察内容 |
| --- | --- |
| 箱线图 | 主样本描述统计选择Outcome，可按Group分组；组顺序、有效n及原方法规则一致。配对连接图是独立变体，不能当通用折线。 |
| 热力图 | 同来源相关计划选择Exposure/Outcome，固定−1到1色标、变量顺序和系数标签；不新增P、星号或聚类。 |
| 散点图 | 原相关结果全部有效记录，X=Exposure、Y=Outcome、Group显示分组；缺组值须提示，不能删点后沿用原n/r。 |
| 折线图 | X=Exposure、Y=Outcome，Group分组。默认同组同X唯一应因重复而拒绝；明确均值聚合后每点n=2，A为1+2X、B为4+2X。按X排序，不把行序冒充时间。另作缺失样本时核对已知X的Y缺失断线，不插值或填零。 |
| 柱状图 | 类别Group：计数14/14、比例50%/50%、总体分母28；均值Outcome为1/4。SD须为样本SD，n不足明确提示；切换模式展示对应语义，不能把记录数当独立人数。 |
| 小提琴图 | Outcome按Group，各n=14、非恒定；核对中位数/四分位、Scott高斯KDE、观测范围截断、组间共用宽度规则。不足3条或常量组应明确拒绝。 |
| 森林图 | 主样本OLS：Outcome结局、Exposure连续、Group分类且A为参考；Exposure系数2、B相对A系数3。效应/区间与原结果一致，不宣称云端重新拟合。 |
| ROC | 冻结评分与阳性定义；曲线、方向、AUC和样本数一致。无独立外部/留出前提时不得虚构DeLong区间。 |
| Kaplan–Meier | 使用上述事件/删失与day口径；风险集、删失、区间、时间标签一致，不新增log-rank/Cox。 |

## 版本、解释和编号

1. 保存并确认配置v1，先将待出图v1加入自动集合，再另存v2。返回历史v1补齐图/解释，确认集合仍用v1，不切换最新v2。
2. 仅改颜色/尺寸生成新版本，核对旧PNG可下载；满足事实/文字兼容条件时，复用解释须形成新绑定并保留派生说明。标题/语义改变后不可无条件沿用旧解释。
3. 每图核对目的、数据、方法、结果、解释、论文描述六节及图版本；不补造P、n或因果结论。作者补充文字仍需本人审核。
4. 新PNG含标题/坐标/单位/图例而不烧录集合序号；独立说明包和原PNG均可下载。旧固定“图1”若冲突应阻断加入规范新集合，不能暗中改图或收费重绘；旧报告仍可下载。
