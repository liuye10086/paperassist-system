### 1. 数值核与独立期望

文件：新增`backend/app/domain/correlation/kernel.py`、`backend/tests/domain/test_correlation_kernel.py`；固定`backend/requirements.txt`。

输入为已选字段共同完整行；上游负责来源/行坐标，数值核再次验证数值/规模/常量并返回统计对象。接口：

```python
compute_correlation(rows: list[list[float]], *, method: str, mode: str, seed: int = 1729) -> dict
```

输出固定`method/mode/n/coefficient/matrix/p_value/confidence_interval/inference/warnings`；非法输入抛带稳定code的`CorrelationError`。不改输入、不含数据库或网络访问。

首个独立期望测试使用以下完整样本，先验证缺失实现导致失败，再实现：

```python
rows = [[1., 2.], [2., 1.], [3., 4.], [4., 3.], [5., 5.]]
result = compute_correlation(rows, method='pearson', mode='pair')
assert result['n'] == 5
assert abs(result['coefficient'] - 0.8) < 1e-12
```

并列秩固定期望`[[1,1],[2,2],[2,3],[4,4]]`为`3/sqrt(10)`；独立Python排列枚举检验小样本P，Fisher区间用标准库`statistics.NormalDist`和`math`对照；不调用生产函数生成期望。再覆盖正负完美/零相关、n=3区间原因、常量/近常量、错维度/非有限/超限和矩阵对称/共同n。

运行：在backend目录用`.venv/Scripts/python.exe -m pytest tests/domain/test_correlation_kernel.py -q`，记录实际red/green；同时测10,000×10和n=500置换边界耗时，未测前不宣称性能目标通过。
