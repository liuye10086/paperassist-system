# 单细胞矩阵主流程实施与验证记录

## 本批结果与边界

沿用 `feat/single-cell-cloud-workflow`，实现不依赖云账号的基础主链：上传矩阵、填写样本信息、导入、一次启动 QC 与基础分析、查看默认图和 H5AD、直接下载 Word。未提交、推送、合并或部署，未改业务数据库。测试数据库仅使用每次创建的隔离 schema；科学计算使用现有本地镜像的新建临时容器，不停止已有服务。

阿里云 EasyGene + OSS 已成为文档中的当前目标。此次提供商切换仅更新文档；已有 AWS 代码保留且默认关闭，阿里云适配、账号资源、香港公网连接和真实 FASTQ 仍未验证。不能把这次本地矩阵测试写成云接入成功。

## 已完成的实现

1. **默认图发布修复。** `bio_figure_store.py` 不再要求或新登记 PDF；默认单细胞图登记 PNG/data/manifest，定量图登记 PNG/TIFF/SVG/data/manifest。历史文件和读取能力保持不动。
2. **样本和文库信息。** `SingleCellImportRequest.samples` 可选填写 sample_id、library_id、donor、batch、group、file_ids。一个导入最多沿用现有 10 个文件限制；文件必须恰好归属一个文库。相同样本可有多个文库，但 donor/group 归属须一致。没有清单时兼容原入口。
3. **多文库组装。** `bio_engine/single_cell.py` 对相同 representation、相同 gene ID 集合及对应符号/feature type 的文库按 ID 对齐，稀疏合并整数 counts。细胞 ID 使用 `library_id:original_barcode`；原 barcode 与文库信息写入映射和 H5AD。基因集合或注释不一致会拒绝，不默默补零或凭 symbol 合并。相同基因集合不等于已经验证参考版本或物种，用户仍须提供正确来源。
4. **一次启动分析。** 新增 `POST /api/v1/projects/{project_id}/single-cell-analysis-runs`，内部复用已有配方、任务和存储。新请求快照记录 direct 执行模式，直接运行包含 QC 的 compute，过程中不再等待 QC 二次确认；旧人工 QC 路径继续兼容。重复请求复用同一个任务。导入阶段原有一次结构核对仍保留。
5. **样本映射贯通。** 导入映射与后续手动映射分别保留：手动映射更新分析用的样本/供者/分组，原始映射保留文库与原 barcode 身份。未确认独立设计时允许探索，不允许把 cell 数充当 donor n。
6. **Word 出口。** 成功单细胞结果提供 `GET .../bio-processed-datasets/{id}/report.docx`。复用既有事实投影与 DOCX 渲染器，从本次保存的 observations 获取实际样本信息，加入输入文件、QC 数值、实际方法/未完成原因、PNG 图与局限。读取受既有项目权限和来源完整性检查约束；不新建报告版本、不调用模型、不生成 PDF，也不运行 PDF 转换。
7. **页面接线。** 导入表单增加可选多文库清单，取消文件选择会同步移除其文库归属；单细胞入口直接填写参数并启动，结果页提供 Word 下载。分析任务复用已有状态轮询和错误显示。

## 使用与后续

矩阵入口支持 MTX 组件/受支持的 tar.gz 包、10x H5、稀疏 H5AD counts。多文库使用同一种格式；H5AD 清单共用一次明确的 counts 数据层及轴字段选择。未实现自动读取任意 H5AD obs 作为样本设计；使用此次清单或已有手动映射入口填写。

导入沿用每文件 64 MiB、展开 512 MiB 等原有限制；基础分析仍为最多 20,000 cells、100,000 features、10,000,000 非零元素及既有运行资源上限。这批没有放宽限制或实现新的资源档位；不能据此承诺处理任意规模云矩阵。

尚未完成：真实生物样本验收、生产运行环境更新/探针、阿里云适配与真实 FASTQ、R 桥接、doublet/ambient/Harmony、自动注释、供者比较及三类专题、全部 22 步验收。当前完成的是基础矩阵主链，不把这些后续步骤标为成功。

复现本地完整链时显式指定已有镜像：

```powershell
$env:MPLBACKEND='Agg'
$env:PAPERASSIST_SC_NUMERIC_TEST_IMAGE='paperassist-client-b06-w1-worker:local'
# 在 backend 目录；数据库配置必须指向项目已配置的隔离测试库。
.venv/Scripts/python.exe -m pytest tests/api/test_single_cell_mainline.py -q --tb=short
```

未设置镜像变量时，该 Docker 主链测试会明确跳过，不把跳过记为通过。
