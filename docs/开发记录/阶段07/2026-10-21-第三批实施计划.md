## 冻结接口

保留 `POST /projects/{project}/manuscripts/{id}/versions/{revision}/exports`。SCI原 `{}` 不变，学校请求使用：

```json
{"school":{"manual_fields":{"author":"","student_id":"","department":"","major":"","class_name":"","supervisor":"","submission_date":""},"manual_chapters":[{"chapter_id":"chapter-1","text":"用户明确提供的人工文本"}],"english_title":"","keywords":[{"chapter_id":"chapter-4","values":["合成资料","学校排版","工程验证"]}],"include_toc":true,"toc_depth":3}}
```

学校缺席school时采用同一明确默认配置，不能丢失请求/幂等比较；SCI不得携带school。manual_chapters仅能对应冻结manual章，keywords仅能对应abstract章，每章最多一项。字段为有限固定键，不接受任意客户端排版/规则JSON。人工字段只属于新导出，不写回原稿快照。

新增 `POST /.../versions/{revision}/exports/preview` 以同一请求返回 `{"schema_version":1,"school":plan}`，只解析固定数据、不生成文件/任务。plan主要字段：

```python
{
 "schema_version":1,"rules_version":"school-export-v1",
 "snapshot_sha256": "digest of original manuscript snapshot",
 "confirmation_id":"frozen id","confirmation_sha256":"frozen digest",
 "analysis_sha256":"frozen analysis digest","options":{},
 "styles":{},"sections":[],"chapters":[],
 "toc":{"enabled":True,"depth":3},
 "label_map":{"figures":{},"tables":{}},
 "requirements":[],"report":{"rules_version":"school-export-v1","issues":[],"can_export":True,"scientifically_verified":False}
}
```

report.issues每项为 `id,kind,severity,location,message,source_evidence`；kind为content/format/manual/unsupported，severity为error/warning/human_review。规则/来源均固定。DOCX export view仅新学校对象增加 `school={plan,report,field_update}`；SCI旧对象不补空键，metadata不动态重算。

根代理渲染接口：

```python
# app/domain/manuscripts/school_export.py
def compile_school_export(snapshot: dict, analysis: dict, options: dict) -> dict: ...
def validate_school_export(plan: dict, snapshot: dict) -> None: ...
# app/adapters/school_docx.py
def build_school_docx(snapshot: dict, images: dict, plan: dict) -> bytes: ...
def complete_school_fields(content: bytes, plan: dict) -> tuple[bytes, dict]: ...
```

`build_manuscript_docx(snapshot,images,*,school_plan=None)`沿原公共数值/来源门禁后分流学校，学校不得走SCI七节校验。学校正文/人工章节/表图用公共段落、表格、图片和确定性ZIP工具；新模块只处理学校顺序/样式/分节、脚注与编号适配。`complete_school_fields`复用Editor、actual update_layout_fields及merge_field_cache；回执只能声明本地渲染器更新，不能冒充Word/WPS人工验收或凭updateFields标记宣称成功。无目录时回执为not_requested。
