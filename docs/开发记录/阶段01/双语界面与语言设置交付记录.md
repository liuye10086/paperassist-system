## 已实现行为

1. **界面语言**：支持 `zh-CN` 和 `en`。匿名切换只保存在内存；登录后从用户偏好恢复，修改成功后持久化，刷新或重新登录恢复。退出或切换账号时清理原账号状态。界面切换不重置当前项目、预览、分析配置或统计结果。
2. **项目输出语言**：项目详情独立保存 `default_output_language`，与名称/研究主题编辑互斥，避免完整项目响应相互覆盖；超时后可重读服务器状态。用户偏好和项目默认语言互不覆盖。
3. **双语范围**：认证、密码表单、项目列表/详情/摘要、Excel上传预览、分析配置、统计表、图表/解释/报告的界面文案、状态、日期和已知错误提示。项目名称、主题、文件名、工作表/字段/组名、单位、原始数值及历史成果正文保持原文。
4. **错误契约**：HTTP 错误为 `detail: {code, message, params}`，保留 HTTP 状态、必要响应头及兼容用的 `message`。前端仅消费已知错误码和按码限制的参数，未知错误使用本地提示。新任务保存 `message_code/message_params`，旧任务读取时兼容，不改写历史 JSON。
5. **持久化与隔离**：`0004_language_preferences` 追加用户与项目语言列，非空、默认 `zh-CN`，CHECK 限定支持值；旧记录默认中文。接口继续执行认证、CSRF、来源、会话有效性和项目归属检查。

接口：

| 接口 | 用途与返回 |
| --- | --- |
| `GET/PATCH /api/v1/auth/preferences` | 当前用户界面语言；PATCH 仅接受 `{ui_language}`，返回同形对象 |
| `GET/PATCH /api/v1/projects/{id}/language` | 当前用户所属项目的默认语言；PATCH 仅接受 `{default_output_language}`，返回完整项目 |
| 登录、`GET /api/v1/auth/me` | 用户公共数据增加 `ui_language` |
| 项目列表、详情与其他公共项目投影 | 增加 `default_output_language` |

**当前边界：** 项目输出语言是未来生成任务的默认设置。本轮未扩展生成引擎；现有分析流程仍生成中文成果。没有翻译或重新生成历史图表、解释、Word 报告，也没有将默认设置回写到已提交任务。任务级语言快照及生成语言由后续对应功能实现。
