## 摘要合约

查询参数 `task_page`、`artifact_page` 为1–1000000的十进制整数，缺省1；`page_size`为1–50，缺省10。按记录时间倒序、kind/id升序；两组列表各自返回 `{items,total,page,page_size}`。分页请求间新增记录可能使行位置移动，每次响应内部来自同一快照。

| 字段 | 内容 |
| --- | --- |
| `project_id`、`project_type` | 经过当前用户归属检查的项目 |
| `tasks.items[].kind` | `statistics`、`boxplot`、`explanation`、`report` |
| `tasks.items[].status` | 原始 `submitting/running/completed/failed/uncertain`；无法识别的持久化状态返回 `unknown` |
| 公共来源字段 | `id/file_id/filename/analysis_run_id/setup_revision/current_revision/engine_version/recorded_at/figure_id/explanation_id`；不适用的关联ID为空 |
| `artifacts.items[]` | `figure/report`及下载文件名、字节数、SHA256、准确资源下载URL；不在摘要请求中读取磁盘或声称文件已通过完整性校验 |
| `future.writing` | `state:not_available`、空`tasks/versions`、`current_manuscript:null` |
| `future.revision` | 同状态、空`tasks/rounds/opinions/pending_materials`、`current_round:null` |
| `future.sci` | SCI时为同状态、空`tasks/recommendations`、`target_journal/submission_progress:null`；毕业论文时为null |
| `future.thesis` | 毕业论文时为同状态、空`tasks`、`school/degree/template/review_progress:null`；SCI时为null |

尚未开放模块的模型只允许空记录，后续阶段建立事实持久化后再扩展类型。`current_revision`仅比较配置版本，不代表原件完整性、工具版本最新或研究结论正确。`recorded_at`对异步请求是创建时间，对同步成功记录是保存/完成时间，不虚构异步完成时间。没有保存的同步统计/报告失败不出现在历史中。

权限：未登录401；其他用户、管理员读取他人项目、无主/不存在项目均404/`project_not_found`。该404触发现有前端整棵工作区清理；普通摘要失败仅影响摘要，不清空编辑草稿或文件预览。原始数据、prompt/payload、云端ID、内部输入快照不进入摘要。
