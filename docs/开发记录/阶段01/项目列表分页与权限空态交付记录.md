## 2. 已验证的后端契约

| 请求或字段 | 结果 |
| --- | --- |
| `GET /api/v1/projects` 无 `page/page_size/q/type` 参数 | 保留旧数组返回合约 |
| 任一列表参数显式出现，包括 `q=` | 返回 `{items, total, page, page_size}`；默认page=1、page_size=10 |
| `page` / `page_size` | 范围分别为1–1,000,000 / 1–100；HTTP仅接受ASCII十进制整数字符串，拒绝小数、科学计数、符号、空白、非ASCII数字及超限，错误返回422 |
| `q` | 去首尾空白后最长120字符；名称字面子串搜索，不区分大小写；空白值不筛选，不搜索研究主题 |
| `type` | 仅接受 `sci/thesis`；省略为全部 |
| 排序及越界页 | `updated_at DESC, id ASC`；越界页items为空，total及请求page保留 |
| `items` | 保留Project已有7字段：id/name/research_topic/project_type/created_at/updated_at/file_count |
| 归属与读取一致性 | owner/type/name过滤使用绑定参数；count/items使用同一只读REPEATABLE READ事务快照 |

## 4. 前端与浏览器证据及限制

前端自动回归已验证以下行为：

- 项目中心显示名称、类型、创建/更新时间、文件数及打开入口；默认每页10项，可选10/20/50。名称提交/Enter搜索，类型即时筛选；改变查询回第1页，清筛选保留页大小。
- 分页列表与当前项目独立，hash直接读取详情；翻页、筛选、无匹配、列表加载/失败均保留工作区，创建清筛选回第1页，PATCH及上传刷新元数据而保留草稿/预览。列表与详情有请求序号、abort及15秒超时保护。
- 仅项目路径HTTP404且 `detail.code === 'project_not_found'` 触发整个项目不可用清理；普通资源404、410与网络失败不得冒充失权。
- 清空失权项目的文件、预览与成果；旧项目、旧工作区实例或旧会话的迟到响应/正文不得清空或恢复当前工作区，包含A→B→A切换。
- 原文件、PNG与Word下载统一由受控请求处理；验证下载失权、401、普通下载失败、成功Blob与资源清理。

根代理在专用schema中使用合成账号/数据亲验：Alice初始23个项目，每页10项共3页、20项共2页、50项共1页；SCI12项、毕业论文11项；名称Enter搜索及无匹配空态可用。翻页、无匹配保留编辑草稿与Excel预览；当前页以外项目从hash刷新后独立恢复；改名移出筛选仍保留预览。
