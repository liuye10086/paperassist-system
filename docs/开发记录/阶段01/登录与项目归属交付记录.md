## 本机账号管理

以下命令均在 `backend` 目录执行；涉及密码的命令要求交互式终端，并读取两次密码，不接受命令行密码参数。

```powershell
# 创建内测用户
.\.venv\Scripts\python.exe -m app.manage_users create --email researcher@paperassist.local

# 管理员通过本机操作重置密码；撤销该用户全部旧会话
.\.venv\Scripts\python.exe -m app.manage_users reset-password --email researcher@paperassist.local

# 停用/重新启用账号，两者都会撤销旧会话
.\.venv\Scripts\python.exe -m app.manage_users disable --email researcher@paperassist.local
.\.venv\Scripts\python.exe -m app.manage_users enable --email researcher@paperassist.local
```

`create --role admin` 可创建另一个管理员角色；同样不能访问他人的研究项目。首次部署必须先使用 `bootstrap`，再创建其他账号。自助注册、邮件验证/找回、网页修改密码和完整后台保留在后续清单。
