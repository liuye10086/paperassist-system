# 最小分析闭环第一步：分析配置

用户已确认只实现最小闭环的第一步：选择描述统计＋箱线图任务、工作表、一个数值列和可选分组列，检查数据并保存配置。本轮不执行统计、绘图、模型调用或报告导出，不自动提交推送。

## 设计与约定

- 复用 openpyxl 安全预检与扫描限制，通过行观察回调统计完整工作表，保留现有前 20 行预览。相比仅分析预览可避免漏掉后续脏数据；相比引入 pandas 不增加依赖。
- 新建 `backend/app/analysis.py`，负责字段概况、选中字段检查及配置接口。列以 Excel 字母定位，重复或空表头也可区分。第一行仍为表头。
- 数值列接受有限整数或浮点数；不将布尔、日期、文本数字、公式和 Excel 错误转换成数值。空单元格、空字符串和纯空白字符串为缺失，NA 等文本保持原义。
- 分组列接受同一种数值、文本或布尔类型；不自动合并类型或去除标签首尾空格。仅使用数值列与分组列均非缺失的记录；最多 20 个有效组，单个组不足 2 行给提示。全部没有有效记录则禁止保存。
- 固定任务 `descriptive_boxplot`、缺失规则 `exclude_selected_missing`；可填写单位。只保存每个文件的一份当前配置，来源 SHA256、工作表、列位置、规则、检查摘要和修订号一并保存。以后运行结果应固定所用配置修订号。
- SQLite 原地升级到 schema 2，仅新增 analysis_setups 表；事务保存并以 expected_revision 防止多个页面覆盖彼此。已有项目、原文件和预览保持可用。
- 接口：GET 文件路径下 `/analysis-profile?sheet=...`、POST `/analysis-check`、GET/PUT `/analysis-setup`。所有接口核对项目归属及原文件完整性，PUT 重新检查数据，拒绝无效输入和过期修订号。
- 新建 `frontend/src/AnalysisSetup.tsx`，在项目中选择分析文件，加载历史配置，选择工作表/字段，显示类型、有效数/缺失数及问题，检查后保存。文件或工作表切换卸载旧请求，保存和检查期间锁定本表单字段。
