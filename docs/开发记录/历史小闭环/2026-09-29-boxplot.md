# 第三步：OpenAI Code Interpreter 分析与箱线图

2026-09-29 用户明确选择 OpenAI 官方 API 的 Code Interpreter 路线：模型在 OpenAI 容器运行 Python 分析并生成图片。图片生成模型也属于后续范围，本步先实现 Code Interpreter。本步已通过真实 API 联调及用户手动验收，用户已授权提交并推送。

## 架构与边界

依据需求 V0.13 §5.5–5.7，实现已保存配置和统计结果 → 显式调用 OpenAI → 云端真实计算与生成带标签、图注的箱线图 → 本地核对并保存 → 预览/下载/恢复。已验收的本地描述统计用于独立核对，不替代云端执行。不采用本地 Matplotlib 渲染器，不在宿主机执行模型代码。

- backend/app/boxplot.py：固定任务的数据提取、独立核算、路由和版本关联。
- backend/app/openai_plot.py：官方 SDK、后台 Responses + Code Interpreter、输出下载和验证。模型实际运行的代码、response/container ID、token 用量和生成环境留存。
- backend/app/storage.py：schema 4 增加图表及请求记录。PNG 保存在 figures/<UUID>.png，元数据、图注、方法、来源在 SQLite。
- frontend/src/BoxplotFigure.tsx：显式生成、后台状态、重新读取、预览与下载；集成到统计结果区域。
- backend/.env 自动读取且被 Git 忽略，环境变量优先。密钥仅在后端；模型通过 OPENAI_MODEL 指定，不硬编码。只调用 https://api.openai.com/v1。

## 执行规则

1. 只发送所选字段的完整有效数值、分组以及绘图所需标签/单位/缺失计数。不发送其他列、项目主题或整个工作簿。字段内容始终作为数据，不作为指令。
2. 模型在 Code Interpreter 中读取 data.json，独立算总体/分组描述统计，生成 boxplot.png 和 result.json；固定任务说明要求图号、标题、轴字段/单位、分组、n 和图内图注。图号 1 是单次分析内编号。
3. 线性 inclusive 分位数、样本 SD、1.5×IQR 须端、完整记录规则沿用既有口径。单条/常数重合线，不去除离群值，不做显著性检验。
4. 本地核对 JSON 中样本数、统计量、须端、离群值、标签/图注及来源；校验下载 PNG 的格式和尺寸。保存云端图片原始字节，不重新绘图。JSON 核对不能证明图片每个像素都正确，仍需人工查看图像。
5. 相同结果/工具版本幂等保存；请求记录在调用前建立，避免重复点击产生多次收费。云端任务 response ID 保存后可刷新/重启继续查询；完成后立即下载，容器产物有过期限制。提交阶段崩溃或超时但未获得 ID 明确标记为状态不确定，不静默重发。
6. 无密钥不影响健康、上传、配置和本地统计；清楚显示配置不足。认证、额度、模型不可用、超时、结果不一致、图片损坏给出可操作反馈。失败不会覆盖旧图。只在用户明确点击重试时重新调用模型。
7. 旧配置图可读可下载，生成必须绑定当前已保存配置。执行中修改配置不能将旧图标成当前结果。当前只展示当前选中结果的图。

## 接口契约

- GET /api/v1/ai/config → {configured, model, message}，不返回密钥。
- 基础路径 .../analysis-runs/{run_id}/boxplot。
- GET → {current_revision, is_current, figure, job}；figure 可空，job 可空。
- POST JSON {expected_revision, retry?: false} → 同上状态。首次/运行中返回 202，已有图 200。失败任务需 retry: true 才重新提交。
- job → {id, status: submitting|running|failed|uncertain|completed, message, response_id, created_at}；GET 对 running 查询云端并完成下载保存，不创建新任务。submitting 超过 180 秒显示 uncertain。
- figure → {id, analysis_run_id, setup_revision, title, caption, x_label, y_label, source_sha256, sha256, created_at, engine:{id,model,provider}, verification:{status,note}, ...}。
- /image?download=true 返回保存的 PNG 附件。所有接口验证项目/文件/结果归属；下载检查原文件及图片哈希。
