## 本批交付链与实现

研究主题及来源文本 → 人工编辑检索式/条件 → 冻结检索任务 → ESearch/EFetch适配 → PMID去重和项目候选 → 原始响应、摘要状态、人工选用及任务追溯。SCI与毕业论文复用相同服务。正式环境真实外发默认关闭，保存任务后持久等待调用配置；离线完整链只用独立测试库的明确合成响应演示。

| 范围 | 本批实现与边界 |
| --- | --- |
| 检索条件 | 默认20篇，可选20/50/100，EFetch每批20，候选每页10；年份/类型默认不限，支持relevance/pub_date。自动补搜0次，修改条件另建任务，不新增模型规划。 |
| 输入来源 | project_topic/section/feedback及其文本快照，保留语言/版本；不提前建设稿件、章节或审稿实体。 |
| 存储 | 新增6表：literature_records、literature_searches、project_references、literature_search_hits、literature_fetch_receipts、ncbi_rate_limits；公共层仅PMID身份，检索内容快照、来源和候选决定按项目隔离。 |
| 获取记录 | 保存实际字段和缺失状态，区分摘要未请求、未返回、空值、失败及已取得；每批原始JSON/XML不可变保存，下载需项目权限；PMC/DOI链接不等于取得全文或已解析DOI。 |
| 可靠性 | 复用Outbox、任务租约、PostgreSQL检查点、等待/恢复、单次发布；项目内24小时缓存保留原获取时间与来源，全部Worker通过同一数据库闸口限制2请求/秒，临时错误按10/30/90秒有限重试。 |
| 候选阅读 | 按本次PubMed返回顺序分页；不同检索各自冻结书目快照，历史详情/刷新/来源分页/保存选择后仍保留本次快照。人工入选/排除与备注有版本冲突保护和历史。 |
| 产品 | 两类项目共用“文献”导航、检索/候选/详情/任务入口，中英文说明、PubMed覆盖与全文限制、NCBI使用版权链接；原书目文本不翻译。 |
| 后续契约 | 预留证据/稳定引用绑定输入契约，未建立内容核验系统或引用编号生成器；稿件外键由阶段06建立。 |

## 配置与外发界限

使用既有 `requests`，没有新增依赖。默认 `PAPERASSIST_NCBI_ENABLED=0`；调用身份通过 `PAPERASSIST_NCBI_TOOL`、`PAPERASSIST_NCBI_EMAIL`、可选 `PAPERASSIST_NCBI_API_KEY` 配置。API Key不是离线实现前置条件。Worker使用私有 `PAPERASSIST_NCBI_CONFIG_FILE` 配置文件挂载，测试堆栈强制关闭并清空身份/Key，不向dispatcher传入NCBI身份。

后续获准联调会向NCBI发送确认后的检索式/过滤条件/PMID和调用身份，不自动发送原始研究主题全文、上传文件、模型输入或候选备注。当前未配置并开放真实调用；原阶段04真实付费联调脚本入口维持关闭；已有模型配置按用户决定保留，本批不调用。

接入规则已只读核对[NCBI使用要求](https://www.ncbi.nlm.nih.gov/books/NBK25497/pdf/Bookshelf_NBK25497.pdf)、[E-utilities参数](https://www.ncbi.nlm.nih.gov/sites/books/NBK25499/pdf/Bookshelf_NBK25499.pdf)和[NLM说明](https://www.nlm.nih.gov/dataguide/eutilities/utilities.html)：无Key默认同IP3请求/秒，有Key默认10请求/秒，提供tool/email。本部署保守采用2请求/秒，不能保证与同公网IP的其它独立软件合计限额。此文档查阅没有调用ESearch/EFetch或外发研究检索内容。
