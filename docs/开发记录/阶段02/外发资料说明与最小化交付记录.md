## 接口与代码位置

只读预览接口为`GET .../analysis-runs/{run_id}/boxplot/disclosure`和`GET .../analysis-runs/{run_id}/explanation/disclosure`。响应包括`version/provider/task_type/source_digest/has_saved_result/summary/labels`；摘要只用于来源核对，不在界面展示。读取预览不创建任务。

真正创建新模型任务时，原业务POST增加：

```json
{
  "external_processing": {
    "version": 1,
    "confirmed": true,
    "source_digest": "来自只读预览的来源摘要",
    "labels": {"numeric_name": "指标", "unit": "单位"}
  }
}
```

标签键随预览固定：分组时还包含`group_name/group:0/...`，解释包含`figure_title`。单项最多160字符，单位允许为空；拒绝缺项、额外项、重复组名及控制/格式/代理字符。服务端在任务创建事务内复核来源，在既有Task JSON中冻结版本、类型、来源、标签、确认人/时间和校验信息；模型调用策略记录`external_processing_version`。

原请求幂等重放、已保存结果和原任务恢复先按既有分支处理，不要求旧正文补确认或改变旧摘要。前端仅在确认后冻结提交正文与幂等键，结果未知时继续使用原请求。
