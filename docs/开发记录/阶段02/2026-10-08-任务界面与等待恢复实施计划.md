## 冻结接口

既有`TaskView`、`TaskEventView`及`/events`、`/model-usage`保持。新增接口：

```text
GET /api/v1/projects/{project_id}/tasks
  page=1, page_size=10 (1..50), status=TaskStatus?, task_type=TaskType?
  -> {project_id, items:[{task:TaskView, source:TaskSource}], total, page, page_size}

TaskSource = {file_id, filename, analysis_run_id, is_current:boolean}

GET /api/v1/tasks/{id}/workspace
  -> {task:TaskView, source:TaskSource, wait:WaitView|null,
      allowed_actions:('resume'|'retry')[], artifacts:{figure,explanation,report}}
figure = null | {title,caption,download_url}
explanation = null | {sections:[{key,title,text}],limitations:string[]}
report = null | {filename,download_url}

WaitView = {id,kind,status,task_revision,input_version,reason_code,error_code,
            created_at,resolved_at}
kind = budget_confirmation | submission_unknown | unsupported_input | unsupported_confirmation
status = open | resolved | superseded
input_version = {setup_revision:int,output_language:'zh-CN'}

POST /api/v1/tasks/{id}/resume
  Idempotency-Key: 必填ASCII可见字符，1..128
  {operation:'resume'|'retry',wait_id:string|null,
   expected_task_revision:int,input_version:{setup_revision,output_language}}
  -> 202 TaskView；回放返回第一次接受时的安全快照，页面随后重新读取当前详情
```

允许动作由后端计算，当前来源已失效时不提供恢复。错误使用现有task_input_invalid、task_revision_conflict、task_idempotency_conflict、task_transition_invalid、task_source_conflict等安全合同；项目列表也纳入请求标识中间件。GET不补写待办、不恢复、不调用供应商。
