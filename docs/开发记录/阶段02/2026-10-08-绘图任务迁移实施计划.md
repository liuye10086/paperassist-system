## 持久化与调用合同

追加迁移 `0010_boxplot_tasks`，不重写旧业务列：

```python
tasks.result_figure_id  # nullable Text FK figures.id，公开任务可返回
tasks.figure_candidate  # nullable JSONB object，仅执行器内部，候选PNG元数据/路径/hash
model_calls.provider_state  # nullable JSONB object，仅网关内部，旧调用保持NULL
```

调用键固定为 `boxplot:v1`；策略位于 `input_snapshot.boxplot_policy`，不修改已冻结来源。网关接口：

```python
ModelGateway.submit_plot(request, instructions=INSTRUCTIONS, payload=payload, execution_lease=lease)
# 每次最多一个外部POST，返回 {'call': persisted_call, 'response': receipt_or_none}
ModelGateway.refresh(call_id)  # 已知响应只GET，先记用量再返回业务内容
```

provider_state按 `container_creating → container_ready → file_uploading → file_ready → response_creating → response_ready` 前进，保存容器、上传文件ID及实际回执路径。每个POST前在有效租约事务中写入开始标记；第一个容器POST前整体call从reserved进入submitting，不能再被当作未提交释放预算。恢复到ready可继续下一步；开始标记无回执为未知，保留预留、等待核对，不自动重放。收到的回执可幂等保存，下一次外部POST仍须重新验证当前租约。

API使用 `PAPERASSIST_PLOT_POLICY_FILE` 指定独立显式JSON策略；`policy.tools`严格为Code Interpreter，容器保持1g及20分钟空闲过期。只通过官方SDK固定官方endpoint，关闭自动重试及重定向；模型输入不能选择工具、网络或任意SDK参数。保留既有 `openai_boxplot_v1`、PNG字节、统计核验、图注和解释/Word来源字段。

创建容器前预留用户、项目、任务三级预算，工具预留必须显式为正。工具费用缺证据时保留待核对，不能把预留额当实际金额，也不能默认为零；token估算超过原预留时仍保留未知工具预留。预算只控制本地准入，不能保证远端实际账单绝不超限。

## 文件、来源与恢复

- 每片仅一个POST或一次响应续取，等待时释放租约、延迟outbox，同一次attempt继续；所有来源和输出处理在后端执行，不在宿主机运行模型代码。
- 终态响应先记用量，再核对来源及下载manifest/PNG。下载有明确大小上限，复用既有数值、标签、PNG尺寸和格式验证；内容仍需人工视觉验收。
- 已知响应在来源变化后继续记账，随后拒绝发布过期图；owner停用时停止网络活动，保留待核对证据。
- 已验证PNG先登记稳定task派生候选ID、metadata、hash/size，再写attempt暂存与原子重命名；最终事务复核租约、来源、原文件及PNG，同时写figure、任务成功与事件。提交失败/未知不删除候选或稳定目标，继任Worker可验证本地文件后发布，即使远端已过期。
- 容器/文件确定过期应显示不可恢复，保留已发生用量及调用；只有用户明确接受再次付费才建新逻辑任务，不在恢复中自动重建。未知提交不能使用这个重试入口。
- GET仅读；页面优先显示已有PNG，轮询不锁工作台，预算恢复沿用原任务；新绘图任务进入项目摘要，旧job照实保留。

## 配置与恢复说明

仓库提供 [绘图策略模板](../../../backend/plot-policy.example.json)，通过 `PAPERASSIST_PLOT_POLICY_FILE` 指向管理员填写的私有JSON文件。模板中的价格、输入估算上界、任务额度与工具预留保留为 `null`，不能直接启用；工具预留还需填写可追溯版本。用户和项目预算沿用第三步的管理命令，不能仅有任务策略而缺少另外两级预算。新策略在创建任务时冻结，Worker只读取冻结内容及自己的密钥文件。

缺少策略或密钥时禁止新绘图，已有PNG、解释和报告照常读取。输入材料超出冻结的估算上界时，原任务保留失败证据；管理员调整策略后，需要显式创建新绘图任务，不能在旧任务中替换价格或额度。页面的再次调用按钮说明可能产生额外费用，本步不填入真实价格、额度，也不进行真实模型调用。

审查补充的恢复边界：

- 每次外部POST的事务内检查再次核对来源，避免Excel复算期间配置变化后继续付费。首个POST之前失败，释放确定未提交的预留并保留审计事件；已创建容器的任务保留工具费用预留。
- 已有容器或上传回执时，达到自动恢复上限后仍可手工继续原任务；三种开始标记缺少回执时仍禁止重发。
- 租约过期后迟到的真实回执会解除不确定状态，由后台重排原任务；明确容器过期则结束为失败。无回执或用户已停用时不重排。
- 数据库提交成功但确认丢失时，重新读取已持久化回执，不将已知阶段降级为未知；PNG本地候选和预算释放也分别覆盖提交中断恢复。

上述边界有隔离测试与只读交叉审查；完整自动验证及开发库升级证据在完成后追加。本计划记录实施过程，正式阶段清单仍以用户已经验收的前四步为准。
