## 全局约束

- 本步仅处理现有绘图/解释；Word仍在服务端整理已有结果，不调用模型。
- 新任务使用用户确认的名称，名称修改不换算或修改数值；原始文件、本地统计、历史图表/解释/Word不改写。
- 标签默认沿用来源，可由用户核对和修改；不声称自动发现所有敏感信息。工作表名、文件名、项目名称/研究主题和内部ID/hash不进入新外发材料。
- 同一任务的分片、自动重试、预算/配置恢复继续使用冻结合同；读旧成果、轮询及原请求重放不重新弹确认。
- 既有任务没有外发合同的快照按原接受行为继续，不能改写已付费请求或旧候选成果；未知提交不重发。
- 本地来源哈希、统计复算、PNG校验、解释事实引用、报告来源核验继续生效；不能以脱敏为由跳过。
- 无真实模型自动测试；使用合成材料、专用测试数据库和模拟供应商。自动验证后用`script/dev.cmd start`供用户验收。
- 前端使用简体中文及既有英文切换，白灰底、深紫主色；不展示内部码、哈希、请求标识。
- 不修改额度、密钥、模型选择、历史预算预留或保留删除策略。无数据库DDL；不创建新分支，不提交推送。

## 锁定的页面与HTTP合同

新生成按钮展开“发送前检查”内联卡，先进行只读GET：

```text
GET .../analysis-runs/{run_id}/boxplot/disclosure
GET .../analysis-runs/{run_id}/explanation/disclosure
```

返回合同如下；`source_digest`仅供程序绑定当前来源，页面不显示。

```typescript
type Disclosure = {
  version: 1
  provider: 'openai'
  task_type: 'boxplot' | 'explanation'
  source_digest: string
  has_saved_result: boolean
  summary: { valid_count: number; excluded_count: number; group_count: number }
  labels: Array<{ key: string; value: string }>
}
type ExternalProcessingConfirmation = {
  version: 1
  confirmed: true
  source_digest: string
  labels: Record<string, string>
}
```

标签键固定为`numeric_name`、`unit`，有分组时增加`group_name`和按原顺序的`group:0`等；解释额外包含`figure_title`。各项允许至多160字符，单位可空，其他必填；拒绝控制字符、未知/缺失键、分组数量变化及同组重复名称。默认显示既有名称；解释默认继承新图表的已确认名称，历史图表仍可在此次解释中改名。UI明确“单位文字修改不会换算数值”。

绘图显示有效/排除记录数、分组数与将发送的标签，说明发送所选真实数值；解释说明仅发送统计汇总和必要图表信息，不上传Excel或PNG。新材料不携带工作表名称；绘图图注去除该来源文字，解释不再强制引用该事实。图标题/轴标签/图注由确认后的文字重新生成，不做全JSON字符串替换。

“确认发送并生成”将`external_processing`加入既有业务POST正文，此时才创建随机`Idempotency-Key`并冻结完整正文；确认按钮本身表达用户决定。重复点击只发一次；超时确认原请求时沿用原正文和键。取消、注销、切换来源或来源变脏清除未提交草稿；迟到预览不覆盖新状态。若预览发现已有成果，则读取已有成果，不开启重生成或覆盖历史。

预览只核对归属与当前来源，不创建任务/调用/预算、不读取密钥。业务POST先处理已有成果、原键重放及原任务恢复，只有确实新建任务时要求外发确认。确认校验、前驱/版本校验与任务保存处于同一事务。新摘要包含规范化确认信息；旧无确认请求保留原摘要算法，不能因新增默认NULL字段破坏旧键。

## 任务一：材料、确认与恢复合同

新增`backend/app/domain/external_processing.py`和必要的独立材料模块；修改`boxplot.py`/`explanations.py`请求类型、两类任务接受、TaskService、TaskExecutionStore、执行器、reports来源校验及两个API模块。不把所有处理堆入一个大文件。

主要函数职责：

```python
def disclosure(snapshot, task_type, user_id, *, has_saved_result=False): ...
def freeze_confirmation(snapshot, task_type, user_id, confirmation): ...
def plot_material(result, original_payload, original_expected, external): ...

def plot_instructions(external): ...
```

`freeze_confirmation`重新计算来源摘要并校验完整标签集合，返回版本、类型合同、标签、来源摘要、服务端确认人/时间及确认摘要。确认记录保存在`input_snapshot.external_processing`，不另复制原始数值数组。实际发送摘要继续由ModelCall保存。新figure保存轻量合同/标签；新explanation的provenance保存合同/标签，用于报告重新构造同一安全事实。新调用策略快照还需明确外发合同版本，原配置文件不要求升级。

旧无合同：原payload、INSTRUCTIONS、来源核验完全保持。新绘图：远端payload只保留`labels/values/groups`，远端expected不要求本地ID/hash；本地保存时从可信来源补回ID/hash。新绘图提示词独立常量，不改变旧全局INSTRUCTIONS。新解释：local_payload与outbound_payload共用替换后的事实，后者去掉本地ID/hash；渲染和`provenance.input_sha256`使用local_payload，ModelCall摘要使用实际出站材料。reports按版本重建local_payload并照常检查每条evidence。
