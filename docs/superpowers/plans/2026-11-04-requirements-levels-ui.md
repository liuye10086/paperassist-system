# 第 3 步研究层级与通用实验 UI

**授权：** 用户要求“先改一版我看看”，并补充“有的实验是通用的”；在现有功能上实现可验收首版，不再另设设计审批，不提交或推送。

**目标：** 需求按研究深度清晰组织，通用实验独立登记，主要模块通过导航切换，保留需求与设计的版本、草稿和来源。

**设计选择：** 采用研究深度浏览（基础分析、深入研究、综合研究）和独立通用能力/实验登记；不使用按层级自动全选的套餐，不把实验锁定在某一层级。层级只组织浏览，不增加持久化等级字段，不从已有内容推断研究等级。具体选择仍写入原有 scope_items 或 experiments，沿用原保存接口。

**结构：** ResearchIntake 顶部切换填写需求、实验设计、材料关联、缺口检查和历史版本；正文使用侧边模块导航。需求拆分研究目标、分析需求、分析细节、已选范围、写作要求、图表交付和联系排期。实验设计拆分通用实验、分组、样本、映射、统计比较、多组学对应与声明。当前模块内部滚动，保存动作留在正文下方。

**兼容边界：** 保留未知/自定义范围和实验、历史质控范围、已完成状态、样本与实验关联、写作材料关联及所有原请求恢复逻辑。通用实验模板仅辅助登记名称，不代表已执行实验或新增分析能力。需求保存与设计保存继续独立。
