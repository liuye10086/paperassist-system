# 新分析模块的详细报告接入要求

适用于本系统以后新增、且已经实现真实计算和固定结果的分析模块。此文档不是尚未开发实验类型的接入声明。

## 固定来源

- 用精确项目、分析结果、图件、解释、语言和有序选材建立不可变上下文；集合解析的是已声明依赖，不能切换到最新结果。
- 报告读原生图和原始结果表。不得为了包装报告重算统计或重新绘图；若用户明确选了重绘，报告只使用该固定重绘。
- 实际读取时校验来源归属、结果身份与原件字节；明确处理来源缺失、损坏、删除待处理和历史版本，不能静默回退其他项目或版本。

## 正文与完整结果

- 使用共用详细正文契约：摘要、设计与数据、质量与可用性、实际方法、主要结果、局限性和阅读/验证建议；每张选定图依序包含读图方式、实际观察、解释和限制。
- 各方法的观测单位、有效样本量、比较方向、缺失、校正范围及不可推断的内容来自该模块实际结果。不能把细胞/空间点/技术重复当独立供体，也不能把稳定性、相关或模型评分写成生物学验证。
- 无图不虚构图。已有解释只在来源、图、事实、语言及验证契约匹配时复用；缺少轴标签、研究设计或图像审读证据时明确说明。不能靠重复套话满足“详细”。
- 正文不出现代码、内部ID、哈希、文件路径、软件版本或原始JSON。必要的科学方法名称、基因名、统计量和单位保留。原始表、参数和技术追溯保存在结果工作簿或复现资料，不能因展示净化而改写原值。
- Word、XLSX和复现包必须对应同一选材与语言。完整所选表保留0/NA/空值、原始精度和顺序；集合按首次选中结果顺序去重，不能扩大为全部项目结果。

## 模型、缓存和发布

- 自动本地导出、prepare、查询、下载、失败恢复和离线重建不得发起付费模型调用。
- 需要增补解读时，复用共用材料预览、外发确认、预算和调用账本。相同固定事实/图字节/顺序/语言/策略复用成功记录；变化时不能误用旧记录。
- 本地复用记录与真实模型响应分别标记来源，不伪造model_calls。保存响应后的重试只恢复原响应，不重复收费。
- 新的导出策略有明确版本和不可变快照。旧请求和历史文件按原版本读取，不批量覆写。多成员正式产物只有全部校验并原子发布后才可见。
- 项目、分析员派单、客户下载及交付冻结/发布分别按现有权限执行。新增报告不绕过服务端权限或交付选材限制。

## 必须提供的定向证据

| 契约 | 必须核对的行为 |
| --- | --- |
| 选材与来源 | 不同项目、来源损坏/删除、旧版本、语言变化、图序变化、明确子集与未选结果 |
| 解读复用 | 匹配解释成功、错图/错语言/错事实拒绝、缺口如实显示、本地复用不调用模型、已保存模型响应重试不重复调用 |
| 数值与科学边界 | 原表逐值相同、零与缺失不互换、各结果独立样本量、比较方向/方法/校正口径准确 |
| 任务与历史 | 幂等、未知响应查询、失败恢复、旧快照/旧下载原字节、跨任务/项目返回拒绝 |
| Word/XLSX/复现 | 中英文、单图/多图及无图能力边界、图件顺序/字节、完整所选表、离线重建、实际版面无裁切 |
| 页面 | 真实入口、固定链接、刷新/后退、草稿恢复、任务返回、历史下载、客户/分析员权限 |
| 新存储 | 隔离库迁移、归属外键、不可变约束、文件引用/删除边界、失败后重试 |

每个模块的验收记录均应列出“入口—共用契约—定向测试—实际文件—Edge”对应证据，并区分代码可确认、隔离工程验证、真实数据/模型、科学验证及用户验收。没有证据的能力保持未验证，不能以其他实验的通过结果代替。
