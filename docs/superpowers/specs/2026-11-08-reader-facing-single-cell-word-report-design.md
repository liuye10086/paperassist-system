# 面向读者的单细胞 Word 报告设计

## 目标

将单细胞结果 Word 从工程证据快照改为面向读者的科研报告：正文用自然语言解释研究设计、质量控制、方法、主要观察、限制和图表；Word 只输出读者正文；结果 ID、来源 ID、SHA-256、完整参数和 JSON 保留在叙述缓存与工程回执中，不进入 Word。中英文导出共享同一结构。

## 范围与边界

- 只改单细胞分析结果 Word 导出，不改原始分析表、图件、manifest 或已有结果版本。
- 真实模型只负责依据已保存事实生成叙述；不得生成或修改数值、P/q、样本数、供者数、方法状态和限制。
- 模型输入使用裁剪后的结构化事实摘要，不发送整份原始 manifest、密钥或无关原始矩阵。
- 模型输出必须是严格 JSON；无法由事实支持的内容写为证据不足，不允许补造生物学结论。
- 生成结果按项目、结果版本和语言缓存，缓存包含模型、提示版本、输入摘要、调用时间、调用状态和正文哈希；已有结果只读保留。
- 下载接口读取已缓存的叙述，不能在用户点击下载时临时发起模型请求。模型不可用时返回受控错误，不静默冒充模型生成正文。
- 本批只生成 DOCX，不生成 PDF；真实模型调用只使用当前本机配置，不接云生信服务、不上传 FASTQ。

## 报告结构

正文顺序固定为：标题与摘要、研究设计与数据范围、质量控制与可用性、分析方法、主要结果、解释边界与限制、图表与图注。表格只保留读者需要的关键结果和明确的“未计算/证据不足”状态。

当前决定：Word 不生成附录，只保留面向读者的正文、关键结果表和图件；可追溯字段继续保存在叙述缓存、原始结果和工程回执中。

## 模型叙述合同

模型输入包含 `report_kind`、`language`、研究设计、样本/供者计数、质量状态、方法名称、关键结果行、警告和限制。输出字段固定为：

- `abstract`
- `design_and_data`
- `quality_control`
- `methods_summary`
- `key_findings`
- `limitations`
- `reader_cautions`

每个字段只能是该语言的自然语言段落或有序短句；模型不得输出 Markdown、代码块、ID、SHA-256、JSON、未提供的数值或因果措辞。校验失败、来源事实不完整或真实模型不可用时不发布新报告。

## 实现方式

新增轻量的读者叙述模块，负责事实摘要、模型提示、严格 JSON 校验和缓存读写；现有 `single_cell_insight_report.py` 只负责将叙述、关键结果和图件组合为正文 DOCX。为当前固定结果提供一次性本地生成命令，写入验收资产目录，供验收服务读取。这样模型调用不发生在下载请求内，且不改动已有结果数据库记录。

## 验证

- 单元测试：Word 不出现结果 ID、SHA-256 或原始 JSON；模型输出严格校验；缺失叙述和模型失败均受控。
- 离线测试：使用 fake provider 验证中英文、不同专题和完整/空结果表。
- 真实验证：使用本机 `backend/.env` 的模型配置生成当前固定结果的中英文叙述，记录调用回执但不打印密钥。
- Word 验证：渲染中英文 DOCX，检查分页、表格和图件；通过验收服务浏览器下载后由用户检查。

## 未包含

阿里云/EasyGene、真实 FASTQ、外部生信计算、独立生物学验证、论文投稿级人工审校和 PDF 交付不在本设计内。


## 当前用户决定

2026-11-08：用户明确要求 Word 只生成正文，不再生成附录。
