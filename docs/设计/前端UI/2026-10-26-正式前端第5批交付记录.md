## 入口与原功能对应

| 内容 | 分层入口 | 保留的业务 |
| --- | --- | --- |
| 评审轮次 | 轮次列表 → 逐条意见 → 当前意见的处理计划 | 固定父稿、原始编号、来源原文、独立译文、定位、材料、冲突及不采纳理由、计划历史 |
| 修改成果 | 有依据改文 / 修改对照 / 逐条回复 | 具体操作、证据与采用关系、预览、显式另存公共新稿；对照与回复按意见逐条展示，保留整份成果各自的固定版本、语言、确认和导出 |
| 多轮流程 | 回传续轮 / 科学补充 / 补料继续 / 实际进展 | 原 Word 回传与续轮关系、科学补充采用、原任务恢复、独立真实进展记录 |
| 项目任务 | 筛选列表 → 任务详情 → 概况 / 待处理 / 成果 / 事件 / 用量 | 原输入版本、状态、等待原因、服务端许可、幂等恢复、成果下载、事件游标和用量记录 |

## 状态与请求保留

- 已访问的轮次、创建入口、修改批次、成果文档和任务按稳定身份保留；切换视图用隐藏方式保存表单状态。任务筛选与分页也在当前项目实例内保留。
- 创建入口按普通新建、固定稿件版本和回传续轮身份分别保留，避免旧草稿被重新绑定到另一父稿。
- 同项目切换模块、浏览器前进后退保留未显示模块的目的地；跨项目继续执行原离开保护和实例隔离。未新增刷新后的自动草稿恢复。
- 隐藏后停止相应读取与轮询；已提交的操作不因视图切换而卸载或中断。真实请求执行中阻止会卸载项目的离开操作，未确认结果与草稿可按原流程核对或明确放弃。
- 原 `round / reviewRun / reviewDocument` 链接继续有效；新增 `view / item` 表示当前视图和意见。明确指定但不可用的固定文档不会替换为其他文档。
- 保留 `allowed_actions`、冻结输入、版本校验、原请求字段和幂等键。`submission_unknown / model_submission_unknown` 继续禁止重发，不因残留许可开放重试。
- 共享分析表单、OCR、整理、排版及 PDF 继续复用原组件；本批仅补充必要的活动状态和离开保护接线，没有替换后端引擎。
