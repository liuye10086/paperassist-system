# PaperAssist 正式前端分批改造方案

**状态：用户已确认六批方案；第1—6批正式前端改造与定向工程验证完成（第6批于2026-10-27收尾），浏览器检查、保留警告和未验证边界见各批交付记录；用户验收待确认。**

**Goal：** 按已确认的 Arviva 新版交互预览改造正式前端，保留现有功能、业务规则、数据和接口；以任务分组、独立页面和视图切换减少整页堆叠。

**Architecture：** 延续现有 React 组件、业务 hooks 和 API。先建立共用设计变量、导航与视图状态约定，再迁移各业务区域。任务控制层保持稳定，展示层每次只呈现当前内容；不把静态预览代码替换成正式业务实现。

**Tech Stack：** 当前项目的 React 19、TypeScript、Vite、CSS；现有 Vitest / Testing Library。shadcn/ui 作为组件风格参考，本轮默认复用当前技术栈，不整体更换框架或样式系统。

**依据：** 根目录 `DESIGN.md`，尤其 6.4；`docs/设计/前端UI/preview-arviva/` 新版预览；2026-10-25 对正式代码的只读核查。

## 1. 当前基线与改造边界

已核对事实：

- 当前分支 `feat/stage10-admin-release`，HEAD 为 `94aa15049adf6fd05163f6a0bd5b7b0018b6d425`。
- 工作区还有已修改、未提交及新增的业务代码，包括 `App.tsx`、`AuthBoundary.tsx`、`ProjectWorkspace.tsx`、`useProjectSelection.ts`、任务导航测试、运营管理及其配置治理模块。**当前工作区内容才是本轮功能基线，不能只从 HEAD 恢复后开始改造。**
- 应用当前组合为 `AuthBoundary → OperationsWorkspace → ProjectWorkspace`，分别承担认证、运营入口、项目工作区；保留各自业务责任。
- 正式前端包含静态预览未展开的 OCR、结构/整理版本、全文与引用、统计模型、图表工作台、集合报告、受控写作、模板适配、多轮评审、回传和配置治理。
- 现有导航使用 hash，包含严格的参数校验和项目访问检查。`files / analysis / artifacts` 的地址恢复尚不完整，内部更新主要使用 `replaceState`；新版前进/后退及主要视图恢复需要正式实现。
- 当前组件混用 `hidden`、`visited` 和 `active`：有的保持实例保存草稿，有的隐藏时卸载内部子组件。直接改成条件 JSX 会有丢失状态或改变请求生命周期的风险。

实施约束：

1. 本轮以 UI、布局、导航和必要的前端状态组织为范围；后端端点、请求语义、权限、任务状态、版本与采用规则保持不变。
2. 现有所有操作都必须有新位置。迁移前记录“旧入口 → 新页面/视图 → 原组件/业务调用 → 验证项”，不能因为预览没有演示就删除。
3. 保留原始文件、稿件、模板、历史成果、备份和运行数据。记录现有差异，不重置或覆盖已有改动；如需隔离环境，也必须完整承接这份工作区基线。
4. 不移植预览里的合成数据、内存保存、统计示例、演示角色或数组下标标识到正式业务。
5. UI 验证使用明确标注的合成材料。真实模型/付费外发、Git 提交/推送、部署与发布不包含在本方案的默认执行范围。
6. 沿用现有服务端 capability 与授权门禁；不把设计改版视为新增真实推荐、科学核验、自动投稿或收费能力。

## 2. 共用交互与状态约定

| 项目 | 正式实现规则 |
| --- | --- |
| 导航层级 | 工作台选择项目；项目概览提供材料、分析、写作、评审四组入口；任务页切换当前内容视图 |
| 主要视图 | 分段按钮只呈现当前内容；列表与详情分开；明确返回入口，保留筛选、分页和选中项 |
| 地址兼容 | 保留现有 `#project=…&section=…` 及任务/文献/稿件/评审/期刊深链；在统一解析器中增加受限 `view` 与实体定位参数，不能绕过访问验证 |
| 实体身份 | 使用真实 file/dataset/run/manuscript/version/round/item/template/journal 等稳定标识；历史插入新条目后仍指向原对象，不使用数组下标 |
| 草稿 | 按项目、业务对象和版本绑定；同一任务内切视图保留，离开或切对象时处理未保存修改；不默认写入浏览器持久存储 |
| 状态生命周期 | 先保留或提升现有控制状态，再拆展示组件；过渡时允许保留已访问面板实例，但只显示当前面板，禁用非当前面板的非必要加载和焦点 |
| 异步任务 | 保留 AbortController、请求代次、会话/项目隔离、幂等和未知结果恢复；隐藏视图不等于取消服务端任务；完成不能抢走用户当前视图 |
| 前进/后退 | 恢复页面、主要视图和实体；未保存时恢复原历史指针后确认，不能覆盖历史项；草稿内容不随历史快照回滚 |
| 核验与外发 | 材料预览、明确授权、冻结版本、采用与导出继续独立；UI 可隐藏技术标识，但请求中的 revision/SHA 等仍完整保留 |
| 滚动 | 桌面常见任务优先首屏呈现视图入口和主操作；长正文、表格和窄屏允许必要滚动，不裁切、不缩小字号强塞 |

这些是实施目标，不能因方案编写完成而勾为验收通过。
