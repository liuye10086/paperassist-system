# 第 2 步上传文件页整理

目标：依据 Edge 中的实际页面，将材料选择、上传和查看文件整理成连贯流程，减少重复按钮和提示。沿用既有 React/TypeScript/Vite 组件及正式接口。

## 界面决定

- 页面主体使用一个统一卡片，顶部切换“上传文件”和“已上传文件”。详情/预览保留返回文件列表与必要操作。
- 删除本页重复的上一步/下一步、返回项目列表及装饰性三段步骤说明，继续使用全局步骤和左侧导航。
- 常规文件、生信数据包为两种上传类型。根据后续用户要求删除独立的单份 Excel 上传预览入口，Excel 统一走常规批量上传；已保存文件的工作表预览仍由文件列表进入。
- 上传区使用统一间距、文件选择区和操作行。压缩重复格式说明；保留文件类型、容量、每批数量等限制及真实状态、失败提示。
- 普通空上传页不显示无批次可读时的刷新按钮；有批次或失败时保留恢复入口。空列表/单页列表不显示无效翻页按钮。
- 生信“已上传批次”直接放在开始上传操作下方；文件列表改用紧凑卡片，上传记录直接显示，均不使用折叠面板。分页按钮集中在页数两侧。
