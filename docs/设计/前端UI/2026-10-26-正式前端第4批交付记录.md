## 入口与视图

| 内容 | 新入口 | 保留的原业务 |
| --- | --- | --- |
| 稿件 | 稿件列表 → 固定稿件版本 → 正文 / 依据 / 检查 / 版本 | 原稿、来源角色、固定历史、公共一致性检查和实际段落定位 |
| 事实稿资料 | 来源 / 方法 / 结果 / 图注 / 冲突 / 引用 / 预览 | 来源版本、方法依据、结果分组、图注分面、矛盾资料和核验引用 |
| 正文 | 默认单章节阅读，可显式切换全文 | SCI 七部分、学校章节、期刊显示上下文；引用可切到实际参考文献 |
| 写作与输出 | 写作 / 导出 / 学校变更独立任务 | 整稿及章节写作、受控授权、科学与语言审核、发布、DOCX/PDF、排版和图语言版本 |
| 学校模板 | 模板列表 / 学校资料 / 新建模板版本；选中模板后详情 / 解析规则 / 规则确认 / 项目绑定 | 原件、分析摘要、章节、冲突决定、文字规范、人工确认、显式绑定及原版本关系 |
| 期刊规范 | 概况 / 研究条件 / 来源资料 / 建议批次 / 指南与检查 / 有限适配 / 投稿记录 | 不可变来源和建议历史、固定目标、指南检查、有限适配、独立投稿纠正链 |
| 期刊来源与指南 | 列表 → 稳定 ID 详情或独立登记表单 | 原文、许可、字段证据、规则提取及人工补充；不以新来源覆盖历史 |

- 已访问的视图、固定稿件版本、写作候选、图语言表单和期刊适配输出用隐藏方式保留实例。切视图不清空未保存内容；固定版本切换按稳定 ID 隔离。草稿仍属于当前项目实例，未新增刷新后的自动恢复；刷新或跨项目会通过离开保护提示。
- 同项目切到其他模块或使用浏览器历史时保留未显示模块的目的地；跨项目依旧通过离开保护和项目实例隔离处理。
- 旧 `manuscript + revision` 链接恢复正文；旧 `adaptation` 链接恢复对应适配。学校详情使用 `template` ID，未知/不完整路由仍拒绝。
- 真实请求执行中阻止会卸载项目的离开操作。未知结果继续保留原幂等恢复入口，但不造成永久的 pending 锁；草稿允许用户明确放弃。
- 继续复用原 API、请求字段、expected revision、SHA、任务恢复、模型 capability、受控授权和原导出组件。没有修改后端引擎、自动采用候选、自动授权或自动投稿。
- 本批仅新增可选共享导出 guard 参数；未传参的其他调用方保持原行为。
