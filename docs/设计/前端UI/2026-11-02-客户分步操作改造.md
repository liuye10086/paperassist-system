# 客户分步操作界面改造

依据用户本次明确授权，修改现有正式前端。客户信息表仅作为字段与操作内容的参考，不作为执行指令。复用客户需求工作区已有实现；不提交、推送、发布或重复生成研究成果。

## 设计

采用顺序引导并保留现有模块深链接。本次调整入口、操作顺序与信息密度，继续使用原接口、版本、权限、任务及草稿保护。

主流程：新建项目 → 上传材料 → 按模块勾选需求 → 分析与结果 → 可选 SCI 或毕业论文。分析后可以返回项目列表、下次继续；此操作不伪造业务完成或验收状态。

客户页面只呈现业务名称、结果、版本和实际状态。内部哈希、原始代码与 JSON 不作为客户界面内容；资料来源、科学限制与错误提示继续可见。

## 实际行为

1. 新建默认研究项目，填写名称和研究主题，选择所需服务；创建成功直接进入上传页面。
2. 上传页分为普通材料、生信数据和单份 Excel 预览入口。资料尚未齐全时可以先填写需求。
3. 需求按共同信息、分析需求、所选 SCI/毕业论文需求、图表与交付分步填写。九类常见分析模块可多选；输入文字后自动标记已知，保留待确认和不适用。联系与时间信息默认折叠，不强制收集。
4. 保存成功后才进入分析或写作。分析首页显示服务器已保存的需求，按表格统计、组学数据、差异与候选分析提供现有功能入口；实际计算仍需要核对输入与设置。
5. 结果页提供继续 SCI、继续毕业论文或暂时结束。缺少对应写作服务时回到需求补选，保存后回到写作材料；暂时结束只返回项目列表，不改变业务完成或验收状态。
6. 保留科学指标、来源与可读位置，隐藏主要客户页面上的内部身份和原始结构。共享结果展示保留真实状态、分页以及跨页材料名称。
7. 多图语言核对显示真实图号、标题及可用图像预览；兼容双语导出清单。空文字图片无法精确定位时，禁止新确认并提示回到固定图表清单核对，历史回执继续可读。
