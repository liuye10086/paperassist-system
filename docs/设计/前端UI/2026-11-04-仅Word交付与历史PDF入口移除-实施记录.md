## 具体修改

1. 稿件、报告、报告集合、排版、意见成果不再挂载历史 PDF 面板，也不为这些面板请求 `/pdf-exports`；继续显示已有 Word、固定版本、排版和任务入口。期刊适配的输出入口文字同步为 DOCX。
2. 历史 PDF 任务保留只读状态兼容，去掉其 PDF 产物链接；研究、生信及交付成果过滤直接 PDF 下载。对 ZIP 依据已知成员、报告清单或 `included_pdf` 判定，保留不含 PDF 的已有成果和独立 ZIP。
3. 交付草稿不静默删选择。已有 PDF 选择和 PDF 必需格式提示用户显式移除，其他备注、需求版本、父快照和修订号保持；含 PDF 的旧冻结快照不重新封包，不提供 PDF 或含 PDF 包下载。旧回执可只读查询；恢复入口按原固定输入核对，不换键生成第二份请求。
4. A19 的 W1 继续继承共享 `Acceptance.writing()`，两类稿件都在 DOCX 下载与哈希核对后结束，不再调用 `self.pdf()` 或写入新的 `published.pdf_id`。共享离线自检中已删除的 `PdfCreateRequest` 导入一并清理，保留其余 6 个实际请求模型检查。
