## 页面安排

1. 顶部统一成果分类：成果列表、研究单图与组图、分析报告与成果包、排版导出记录。选中成果仍按固定标识和页码读取。
2. 成果内容在前，稿件下载、交付登记、继续写作在后；移除重复导航、保存提示和空列表分页。
3. 成果采用紧凑卡片，详情的来源、尺寸和方法直接展示。图和报告保留版本列表、生成入口及草稿保护。
4. 分页按钮与页码居中；窄屏使用单列，来源表单和下载项保持可读。
