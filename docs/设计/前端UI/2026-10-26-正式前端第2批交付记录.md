# 正式前端第2批：材料与文献

状态：第2批代码改造、定向工程验证及浏览器效果检查完成（2026-10-26）；等待用户查看效果。真实业务验收与下述工程验证分别记录。

本批以第1批完成后的工作区为基线。保留既有未提交业务修改，改造正式 React 页面，继续使用原 API 和业务组件。开发前快照与日志保存在被 Git 忽略的 `script/.runtime/ui-batch2-20261026/`。

## 入口迁移

| 原入口 | 新位置 | 保留的业务能力 |
| --- | --- | --- |
| 材料页同时展开上传、列表和预览 | 文件列表 → 上传文件 / 文件详情 / 预览 | 原件下载、分页、批量上传、失败项重试、Excel 工作表与单元格溯源 |
| 文件详情内纵向堆叠用途、引用、生命周期及解析 | 文件详情内切换任务视图 | 用途版本冲突、原始引用计数、生命周期影响确认、文档解析与 OCR 校对 |
| 数据结构与整理入口 | 文件详情的数据任务 | 结构版本、整理规则、质量版本、人群筛选及回执 |
| 文献页同时展开检索表单、历史、候选及详情 | 候选列表 / 新建检索 / 检索历史 / 候选详情 | PubMed 检索条件、历史来源、分页、筛选备注、原始记录与快照 |
| 文献页展开证据工作区 | 论述与证据核验内切换任务 | 摘要、PMC、上传材料、论述版本、人工核验、辅助任务与外发门禁 |
| 文献页展开引用工作台 | 引用工作台内切换候选、样稿与编辑预览 | 书目信息、引用版本、冲突恢复、保存版本预览和复制 |

## 导航与状态

- 材料主要页面使用 `#project=…&section=files`，`view=upload`，或 `view=detail|preview&file=…`。
- 文献主要页面使用 `#project=…&section=literature`，`view=search|history|evidence|citations`，或 `view=detail&reference=…`；继续兼容原 `search=…` 深链。
- 统一解析器拒绝重复参数、非法 ID、视图与实体不匹配的地址。使用真实实体 ID；跨项目和失权时清除绑定。
- 已访问编辑视图保留组件实例，同一项目内切换不把草稿写入浏览器持久存储。后台异步结果不得自动跳转当前页面。
- 返回列表恢复当前分页与筛选；文件上传成功仍按原行为刷新第一页。
