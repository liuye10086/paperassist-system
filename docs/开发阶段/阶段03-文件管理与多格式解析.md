## 范围与现有基线

现有系统可上传单个 `.xlsx`、保存原始字节与哈希、预览工作表和前20行、检查字段、保存配置，并保留解析失败记录。当前使用第1行作为表头，不计算公式、不恢复合并布局，也未完成多文件批量上传、Word/PDF/图片解析、后台重解析与独立解析进程。本阶段保留这些既有数据口径，任何新增清洗均显式记录，不静默改值。

首批拟支持 `.xlsx`、`.docx`、`.pdf`、`.png`、`.jpg/.jpeg`，具体子格式边界经用户确认及样本验证后固定。扫描 PDF 和图片识别得到的数字须标注识别来源与不确定性，不能当成已核验的原始数值。学校模板在此阶段提取内容及原始样式信息，完整学校规则与排版验收由毕业论文阶段完成。

## 四、验收

本阶段测试资料使用合成或获准使用的脱敏文件。文档编写期间不安装 OCR、模型权重或解析依赖；实际引入时核对固定版本及所需模型的使用条件。

- [ ] S03-QA01 同批上传有效、损坏及超限文件，逐文件状态正确，同名文件不覆盖，刷新和重启后可恢复。
- [ ] S03-QA02 用多表、重复表头、合并单元格、公式、空行、极端数值及异常尺寸 Excel 样本验证无静默改值。
- [ ] S03-QA03 用含标题、表格、图片和样式的 Word 样本核对结构与来源，模板原始样式仍可读取。
- [ ] S03-QA04 用文字版及扫描版 PDF、清晰及低质量图片验证页码、区域、OCR 不确定项和人工确认路径。
- [ ] S03-QA05 检查解析字段的单位、空值与来源，确认只含图片时不会产生未提供的样本量、P值或实验方法。
- [ ] S03-QA06 连续建立两次清洗与两次解析版本，确认原始字节、旧数据、旧任务输入及导出结果不变。
- [ ] S03-QA07 注入解析超时、进程退出和保存失败，任务进入明确状态且可恢复，API不会无限等待。
- [ ] S03-QA08 用两个账号验证所有文件入口与引用路径，跨用户预览、下载、修正和删除均被拒绝。
- [ ] S03-QA09 在浏览器完成批量上传、来源核对、识别修正、清洗确认及历史版本切换，并记录语言和排版限制。
- [ ] S03-QA10 运行相关回归测试及构建检查，按样本记录支持的格式、规模和解析耗时，不将配置上限当作容量实测结论。
- [ ] S03-QA11 用已知重复、异常、时间字段和相关字段的合成数据，核对识别位置及提示，确认无自动删除或因果结论。
