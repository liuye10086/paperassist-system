# 阶段07：毕业论文与学校模板

当前代码已于2026-10-07按职责整理，目录职责及旧新路径映射见[项目结构](../项目结构.md)；本页拟新增项仍是后续计划。

版本：V0.1\
更新日期：2026-09-29\
目标：按已确认的学校模板与写作规范生成毕业论文，并复用公共写作、引用和导出能力。\
依据章节：需求§2.3—2.5、§4.1—4.2、§4.4、§7.1—7.6、§8；技术方案§5、§8.1、§8.3—8.4、§14.1、§16。\
前置依赖：阶段06共用写作引擎与 DOCX/PDF 导出；复用阶段03解析、阶段04分析和阶段05文献能力。\
涉及代码位置：现有 `backend/app/api/projects.py`、`backend/app/domain/reports.py`、`backend/app/adapters/report_docx.py` 和 `frontend/src/features/projects/ProjectWorkspace.tsx`、`frontend/src/features/reports/WordReport.tsx` 可复用或扩展；`backend/app/templates/`、`backend/app/writing/`、`frontend/src/templates/`、`frontend/src/manuscripts/`、`backend/tests/test_templates.py` 均为拟新增，写作与稿件目录由阶段06建立。

毕业论文与 SCI 共用资料整理、证据核验、章节写作、数值检查、版本和导出服务，不复制两套引擎。章节与格式以适用学校规范为准，常见章节只是示例。先支持已验证模板，未知模板明确展示解析限制；导师与评审意见的逐轮处理在阶段09完成。

- [ ] S07-QA03：规范冲突未确认前不会直接用于生成。
- [ ] S07-QA04：未知模板展示限制，不宣称任意模板完整还原。
