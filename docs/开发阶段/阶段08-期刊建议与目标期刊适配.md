# 阶段08：期刊建议与目标期刊适配

版本：V0.1\
更新日期：2026-09-29\
目标：为 SCI 项目提供可核实的期刊候选，并按用户确认的目标期刊调整稿件。\
依据章节：需求§2.2、§3.1—3.2、§4.1—4.3、§6.4、§6.8、§8—9；技术方案§5、§10—13、§16。\
前置依赖：阶段05检索与来源基础、阶段02任务服务；初稿前可启动候选建议，实际稿件格式调整依赖阶段06，不要求先生成整篇论文。\
涉及代码位置：现有 `backend/app/projects.py`、`config.py`、`main.py` 和 `frontend/src/ProjectWorkspace.tsx` 可复用或接入；`backend/app/journals/`、`frontend/src/journals/`、`backend/tests/test_journals.py` 均为拟新增；稿件版本与导出复用阶段06拟新增的 `backend/app/writing/`、`backend/app/exports/`。

候选建议与实际期刊格式调整分成独立任务。优先使用可核实的官网、作者指南和期刊数据；SCI/SCIE、JIF、JCR 等指标是否接入需单独确定来源和许可，未接入不阻塞普通匹配。系统不代替用户投稿，不估算录用概率或承诺发表时间。

## 1. 数据库与持久化

- [ ] S08-DB01：保存稿件领域、主题、文章类型、标题、摘要及主要结果快照。
- [ ] S08-DB02：保存目标学科、发表语言、开放获取偏好及费用预算。
- [ ] S08-DB03：保存学校或单位的期刊要求。
- [ ] S08-DB04：保存期刊名称、官网、收稿范围及可接收文章类型。
- [ ] S08-DB05：保存每个期刊字段的来源、核实日期和待核实状态。
- [ ] S08-DB06：保存已核实费用、开放获取政策、审稿时长及适用条件。
- [ ] S08-DB07：保存收录、影响因子、分区的数据来源、年份和评价体系。
- [ ] S08-DB08：保存建议批次、匹配理由、排序依据和所用信息快照。
- [ ] S08-DB09：保存用户确认的目标期刊及确认记录。
- [ ] S08-DB10：保存作者指南来源、版本、核实时间及提取要求。
- [ ] S08-DB11：保存格式检查项、调整依据、输入稿件与输出新版本。
- [ ] S08-DB12：单独保存用户记录的投稿、返修、录用或发表进展。

## 2. 后端与接口

- [ ] S08-BE01：接受初稿前的研究资料或初稿后的稿件信息发起建议。
- [ ] S08-BE02：论文内容或投稿偏好变更后生成新的建议批次。
- [ ] S08-BE03：按收稿范围、文章类型及相关研究内容进行匹配。
- [ ] S08-BE04：纳入学科、语言、开放获取、预算及单位要求。
- [ ] S08-BE05：从已确认来源获取期刊官网、作者指南和候选信息。
- [ ] S08-BE06：按受控访问规则限制网页地址、重定向和内部网络访问。
- [ ] S08-BE07：为每个候选生成基于资料的匹配理由和投稿注意项。
- [ ] S08-BE08：未知字段标记待核实，禁止凭模型记忆补造。
- [ ] S08-BE09：收录、影响因子和分区仅在来源、年份及体系核实后展示。
- [ ] S08-BE10：禁止用 PubMed 可检索推断 SCI/SCIE 收录。
- [ ] S08-BE11：费用、开放获取政策和审稿时长保留条件及日期。
- [ ] S08-BE12：不输出录用概率预测或发表时间承诺。
- [ ] S08-BE13：用户确认目标期刊后固定作者指南与要求版本。
- [ ] S08-BE14：检查当前稿件篇幅、章节、摘要、图表和引用格式。
- [ ] S08-BE15：生成调整项，并标明自动处理范围及待确认问题。
- [ ] S08-BE16：依据已核实指南调整章节名称、顺序和格式并记录依据。
- [ ] S08-BE17：通过阶段06生成调整后的新稿件版本与 DOCX/PDF。
- [ ] S08-BE18：提供候选批次、目标确认、指南和检查结果接口。
- [ ] S08-BE19：提供实际投稿进展的用户记录接口，与任务状态分开。
- [ ] S08-BE20：预留后台配置期刊来源、更新情况和推荐规则的接入点。

## 3. 前端交互

- [ ] S08-FE01：初稿前可填写稿件信息并发起期刊建议。
- [ ] S08-FE02：初稿后可选择稿件版本并填写投稿偏好。
- [ ] S08-FE03：展示候选名称、官网、范围、匹配理由及投稿要求。
- [ ] S08-FE04：展示字段来源、核实日期、适用条件和待核实标记。
- [ ] S08-FE05：收录、影响因子或分区同时展示年份与评价体系。
- [ ] S08-FE06：查看历史建议，并在稿件或偏好变化后重新发起。
- [ ] S08-FE07：确认目标期刊并查看所用作者指南版本。
- [ ] S08-FE08：展示篇幅、章节、摘要、图表及引用的调整清单。
- [ ] S08-FE09：查看调整依据、新稿件版本及公共导出结果。
- [ ] S08-FE10：由用户记录实际投稿进度，不随任务完成自动更新。
- [ ] S08-FE11：项目中心展示目标期刊、建议批次及实际进展。
- [ ] S08-FE12：来源不可用时说明缺失内容并保留已核实建议。

## 4. 验收

- [ ] S08-QA01：没有初稿时仍可依据研究资料生成候选。
- [ ] S08-QA02：有初稿时建议绑定所选稿件版本和偏好快照。
- [ ] S08-QA03：每个候选理由可对应范围、文章类型或相关内容依据。
- [ ] S08-QA04：缺字段保持待核实，不出现模型补造信息。
- [ ] S08-QA05：PubMed 收录不会被当成 SCI/SCIE 证据。
- [ ] S08-QA06：展示的评价指标具有来源、年份、体系及适用权限。
- [ ] S08-QA07：费用和时长信息有条件及日期，无录用概率或时间承诺。
- [ ] S08-QA08：指南变更或重新建议不覆盖历史建议及所用快照。
- [ ] S08-QA09：格式调整生成新版本，七部分变更有核实指南依据。
- [ ] S08-QA10：调整稿的数值、图表和引用关联通过公共一致性检查。
- [ ] S08-QA11：任务完成不自动变更投稿、录用或发表状态。
- [ ] S08-QA12：受控网页访问拒绝内部地址，项目资料权限有效。
