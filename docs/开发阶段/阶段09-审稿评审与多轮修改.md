# 阶段09：审稿评审与多轮修改

当前代码已于2026-10-07按职责整理，目录职责及旧新路径映射见[项目结构](../项目结构.md)；本页拟新增项仍是后续计划。

版本：V0.1\
更新日期：2026-09-29\
目标：逐条处理 SCI 审稿及毕业论文反馈，保留真实修改、回复、对照说明与多轮版本关系。\
依据章节：需求§2.4—2.5、§3.1、§4.2—4.4、§5.8、§6.9、§7.6—7.7、§8—9；技术方案§5.4、§8.4、§9、§11—14、§16。\
前置依赖：阶段04真实重分析、阶段05文献补充、阶段06稿件和公共导出；毕业论文分支依赖阶段07，SCI 目标期刊适配依赖阶段08，学校分支不强制依赖期刊能力。\
涉及代码位置：现有 `backend/app/domain/analysis.py`、`backend/app/domain/boxplot.py`、`backend/app/domain/explanations.py`、`backend/app/domain/reports.py` 和 `frontend/src/features/projects/ProjectWorkspace.tsx` 可复用或接入；`backend/app/reviews/`、`frontend/src/reviews/`、`backend/tests/test_reviews.py` 均为拟新增；复用前续阶段拟新增的 `backend/app/writing/`、`literature/`、`templates/`、`journals/`、`exports/`。

两类项目共用意见拆分、计划、等待恢复、版本和修改说明服务。SCI 另生成逐条审稿回复；毕业论文按学校规范检查。修改始终绑定明确稿件和意见轮次，新实验和数据由用户提供。首版建议使用独立修改对照，原生 Word 修订痕迹需另行验证。

定位以章节标题、稳定段落标识和图表编号为基线。只有渲染器确实给出且可核对时才附加指定 PDF 的页码或行号；DOCX 在不同 Word/WPS 版本、字体和打印设置下可能重新分页，不宣称与 PDF 或其他软件页码一致。

## 4. 验收

- [ ] S09-QA01：各来源意见原文、编号和轮次保持完整且可追溯。
- [ ] S09-QA02：SCI 编辑和多位审稿人意见可区分并逐条处理。
- [ ] S09-QA03：导师、评阅及答辩后意见进入毕业论文分支。
- [ ] S09-QA04：含糊、冲突和结论调整进入确认状态而非自动采纳。
- [ ] S09-QA05：需要新增实验时保持待补充，不产生虚构完成陈述。

- [ ] S09-QA10：回复语言可独立选择，原意见不被译文覆盖。
- [ ] S09-QA11：稳定定位能找到最终稿改动；附加 PDF 页码或行号与指定文件一致，不假定 DOCX 同页。
