# 阶段04：数据分析与图表报告

版本：V0.1\
更新日期：2026-09-29\
目标：把固定描述统计闭环扩展为可确认、可追溯的科研分析模块。\
依据：需求§2.5、§5.4—5.8；技术方案§2.2、§5.3、§6、§13、§16。\
前置：阶段02任务/预算、阶段03数据版本。PDF报告在阶段06公共导出能力完成后验收。

架构：分析计划固定输入版本；工具真实计算；图表、解释、报告绑定同一结果版本。延续 Code Interpreter 云端绘图与本地独立统计核对，不在宿主机运行模型生成代码。

代码入口：现有 `backend/app/analysis.py`、`descriptive.py`、`boxplot.py`、`openai_plot.py`、`explanations.py`、`explanation_content.py`、`reports.py`、`report_docx.py`；现有前端 `AnalysisSetup.tsx`、`StatisticsResults.tsx`、`BoxplotFigure.tsx`、`AnalysisExplanation.tsx`、`WordReport.tsx`。拟按需新增 `backend/app/analysis_tools/`、分析工作流及结果Schema，保持已有测试可迁移。

现有基线：描述统计、箱线图、中文六段解释、Word报告已形成小闭环。下面条目表示正式模块的补齐、扩展与重新验收，不代表全部从零开发。具体统计方法是待决策项；九类图表来自需求示例，按已确认方法逐项实现，不将图形名称当作统计方法。

跨阶段边界：本阶段先交付结果/图表/报告契约，稿件关联由阶段06建表时接入；PDF在阶段06完成后补验，审稿重算联动在阶段09完成后补验。这些联动条目继续保持未勾选，不阻塞先完成分析核心链路。

### 2.2 真实统计能力

以下扩展是技术方案候选；每项在方法清单获确认后实施。使用适用的 SciPy、statsmodels、lifelines、scikit-learn 等组件，具体版本在接入时固定。

- [ ] S04-BE14：生成字段概况、缺失比例、异常/重复提示和清洗摘要。
