# 阶段10：管理后台与发布准备

版本：V0.1\
更新日期：2026-09-29\
目标：补齐管理员、运行维护与发布验收；收费能力仅在产品规则确定后实施。\
依据：需求§3.2、§8—9及末尾待定事项；技术方案§13—18。\
前置：阶段01—09适用功能已验收；基础权限、用量和预算在阶段01/02已实现，不推迟到本阶段。

架构：运营记录、研究内容权限和收费账目分别管理；后台调用现有业务服务。拟新增管理API/页面、配置版本与审计模块、`infra/`、备份恢复脚本及运行手册；现有 `backend/.env.example`、README和配置模块逐步扩展。

当前基线：代码尚无管理员后台和支付系统。支付/定价来自技术方案的发布建议，并非V0.13已确定需求；无需收费的试用不强制接入支付。

## 2. 后端与接口

### 2.1 管理员功能

- [ ] S10-BE01：提供用户查询与状态管理，禁止越权提升角色。
- [ ] S10-BE02：提供用户权限配置，管理员运营权不自动授予所有研究内容读取权。
- [ ] S10-BE03：查询系统任务的用户、项目、类型、阶段、状态与耗时。
- [ ] S10-BE04：查询异常任务的可公开原因、内部诊断标识和关联执行记录。
- [ ] S10-BE05：管理员重试任务沿用业务权限、状态与幂等检查；终止能力按D31批准范围实现。
- [ ] S10-BE06：查询API请求量、失败/重试、限流、模型与工具使用情况。
- [ ] S10-BE07：按用户、项目、任务、模型和时间统计Token及费用。
- [ ] S10-BE08：区分实际用量、估算成本、待核对消耗和用户收费。
- [ ] S10-BE09：配置模型ID、工具能力、超时、输出限制和预算，启用前做样例验证。
- [ ] S10-BE10：配置NCBI调用身份、限流与缓存，隐藏秘密字段。
- [ ] S10-BE11：管理提示词、Agent分工和工作流版本，支持验证后发布及回退。
- [ ] S10-BE12：查询脱敏运行日志，按request/task标识关联错误。
- [ ] S10-BE13：查询文件数量、存储占用、孤立文件与失败清理记录。
- [ ] S10-BE14：配置单文件/单项目/数据规模/并发等已批准基础参数。
- [ ] S10-BE15：管理期刊信息来源、更新计划、失败情况与推荐规则。
- [ ] S10-BE16：管理学校模板支持清单、解析规则和冲突处理配置。
- [ ] S10-BE17：管理审稿/评审处理规则、等待条件和导出设置。
- [ ] S10-BE18：关键配置修改保留旧版，正在运行的任务继续绑定原配置快照。

### 2.2 隐私、删除与存储维护

- [ ] S10-BE19：按确认期限处理原始文件、派生数据、图表、稿件和导出文件。
- [ ] S10-BE20：删除范围覆盖检查点、模型调用记录、检索材料和临时文件。
- [ ] S10-BE21：删除项目先处理在途任务，避免删除后Worker重新写回产物。
- [ ] S10-BE22：校验外键及资产引用，避免清理被其他有效版本使用的文件。
- [ ] S10-BE23：删除失败可重试、有进度及审计，不能只隐藏列表记录。
- [ ] S10-BE24：备份内数据按保留策略到期处理，向用户说明与主存储删除的差异。
- [ ] S10-BE25：对第三方已发送资料按供应商实际能力处理并记录，不能承诺本地删除等于外部即时删除。
- [ ] S10-BE26：私有对象存储接入后验证签名下载、过期、对象权限和迁移完整性。
- [ ] S10-BE27：管理存储配额与临时文件清理，达到配额时保留已有成果并明确提示。

### 2.3 条件性收费能力

本节需用户确认收费范围、渠道、定价、失败/取消/退款规则后开始。若本次仅内测，登记“暂缓及原因”，不要直接勾选为完成。

- [ ] S10-BE28：实现获批准的套餐或余额模式，不同时默认建设多套商业模式。
- [ ] S10-BE29：任务启动前原子预留额度，结束后按确认规则结算或释放。
- [ ] S10-BE30：支付创建、状态查询和到账确认使用服务端可信结果。
- [ ] S10-BE31：验证支付回调签名、订单金额/币种、重复和乱序事件。
- [ ] S10-BE32：分别实现成功、失败、重试、取消、结果未知的计费规则。
- [ ] S10-BE33：实现退款申请/执行/失败恢复及对账，不改写已发生的API消耗。
- [ ] S10-BE34：提供消费记录、费用明细和支付异常处理。
- [ ] S10-BE35：对账差异保留证据并进入人工核对，不自动补造成功支付。

### 2.4 部署与可恢复性

- [ ] S10-BE39：数据库/消息端口限制到必要网络，密钥不写入镜像或前端包。

- [ ] S10-BE41：备份数据库与文件对象的一致版本，并核对校验值。
- [ ] S10-BE42：在独立恢复环境重建项目、任务、来源关系及可下载成果。
