# 阶段05：文献检索与引用核验

版本：V0.1\
更新日期：2026-09-29\
目标：为两类论文的生成及修改提供可追溯的 PubMed 检索、证据核验与引用能力。\
依据章节：需求§2.4—2.5、§4.2、§6.5—6.6、§7.5、§9；技术方案§5、§7、§11—13、§16。\
前置依赖：阶段01的归属权限、阶段02的统一任务与模型调用、阶段03的文件解析；可与阶段04统计扩展并行。\
涉及代码位置：现有 `backend/app/config.py`、`main.py`、`projects.py`、`storage.py`、`openai_explanation.py` 和 `frontend/src/ProjectWorkspace.tsx` 可复用或接入；`backend/app/literature/`、`frontend/src/literature/`、`backend/tests/test_literature.py` 均为拟新增。

复用阶段02的模型适配、任务恢复和预算控制，以及阶段03的用户全文解析；SCI 与毕业论文调用同一文献服务。技术方案中的 Bio.Entrez、证据状态和引用适配器是推荐实现，具体选型在对应决策完成后落地。本阶段不默认建设共享全文下载库。

本阶段先落地文献、项目证据和引用绑定契约，以固定样稿验证引用编号；阶段06建立稿件表时再创建稿件引用外键，不要求阶段05提前建立稿件表。章节与意见来源先保留任务输入快照，后续模块建立实体时再补相应关联。

- [ ] S05-DB07：保存项目候选、选用状态及其所属检索任务。
- [ ] S05-DB08：分别保存摘要与全文的实际获取状态、来源和读取范围。
- [ ] S05-DB09：保存用户全文文件与书目记录的项目内关联。
- [ ] S05-DB10：保存论述、支持依据、来源位置与核验状态。

- [ ] S05-DB12：定义稳定文献 ID、段落标识和稿件版本的引用绑定契约，稿件外键由阶段06落地。

- [ ] S05-BE03：组合 PubMed 可执行检索式并应用已确认检索条件。
- [ ] S05-BE04：通过 NCBI E-utilities 的 ESearch 获取 PMID。
- [ ] S05-BE05：通过 EFetch 获取书目记录及可用摘要。
- [ ] S05-BE06：实现 NCBI 调用身份配置及多 Worker 总体限流。
- [ ] S05-BE07：处理缓存、接口失败和有限退避重试。
- [ ] S05-BE08：对候选文献按 PMID 去重并保留检索来源。
- [ ] S05-BE09：按研究问题、对象和章节主题筛除明显无关候选。
- [ ] S05-BE10：只读取实际取得的摘要或全文，并记录核验范围。
- [ ] S05-BE11：核对方法、结果和结论是否支持拟写论述。
- [ ] S05-BE12：区分文献存在、DOI 可解析与内容支持论述三项检查。
- [ ] S05-BE13：仅有摘要时禁止生成未提供的数据、方法细节或亚组结论。
- [ ] S05-BE14：部分支持时收窄表述或提出补证据要求。
- [ ] S05-BE15：证据冲突或材料不足时标记待核实，不作为已确认依据。

- [ ] S05-BE18：禁止补造缺失 DOI、摘要、年份、文献或研究结论。
- [ ] S05-BE19：按已确认引用格式生成正文引用及去重参考文献列表。
- [ ] S05-BE20：段落增删后统一重排编号并检查正文与列表对应。
- [ ] S05-BE21：提供项目候选、证据、来源和引用关系的查询接口。
- [ ] S05-BE22：供 SCI、毕业论文及多轮修改调用同一检索核验流程。
- [ ] S05-BE23：沿用任务权限、等待恢复、模型预算和输入版本校验。

## 4. 验收

- [ ] S05-QA01：同一 PMID 多次检索只产生一条书目及正确项目关联。
- [ ] S05-QA02：候选记录可追溯到实际检索式、时间与来源。
- [ ] S05-QA03：缺失 DOI、摘要和年份保持缺失，不出现补造内容。
- [ ] S05-QA04：仅摘要样例不会引用未读取的全文细节。
- [ ] S05-QA05：文献存在但不支持论述的负例被拒绝用于支持该句。
- [ ] S05-QA06：部分支持、证据冲突和材料不足分别触发正确处理。
- [ ] S05-QA07：使用固定样稿增删段落，验证引用编号和参考文献对应且无重复孤立项。
- [ ] S05-QA08：SCI 与毕业论文使用同一服务并保持项目资料隔离。
- [ ] S05-QA09：限流、获取失败、重试和恢复不生成重复候选关系。
- [ ] S05-QA10：摘要与全文的显示状态符合实际获取记录。
- [ ] S05-QA11：样例核验可由人工打开来源复查支持依据。
- [ ] S05-QA12：真实 NCBI 联调按阶段00范围执行并记录结果与限制。
