## 范围与现有基线

现有小闭环已保存绘图及解释的云端请求、任务状态和结果，并通过后台扫描恢复；README记录了相关测试与用户验收。本阶段不把这些能力重复列为新功能，重点是迁入统一任务契约，保留已有项目、输入版本、云端响应标识与成果。当前未接入 Celery、RabbitMQ 或 LangGraph，多用户调度能力尚未完成。

绘图继续使用用户已确认的 OpenAI 官方 Responses API + 托管 Code Interpreter。本地描述统计保留为独立核对依据；不在宿主机执行模型生成代码，不改为本地重新绘图。GPT Image 是后续独立能力，本阶段仅预留适配接口和用量类别，不以其替代统计图。收费账本、支付和退款仅在用户确认收费范围及规则后于阶段10实施，不作为本阶段或基础发布的必选项；本阶段处理供应商实际用量、内部估算与预算控制。

推荐实现为 Celery + RabbitMQ 负责领取与分发，LangGraph 负责有状态流程、检查点和等待；PostgreSQL 业务记录为用户任务状态的唯一依据。这一组合仍是拟实施选择，应在实施前完成兼容性核查并记录决定。无需因该推荐另行要求用户部署一套 PostgreSQL 或先作 Docker 选择。

本系统可保证自身记录与副作用的幂等约束，不能承诺外部模型调用严格“恰好一次”。供应商已执行但响应遗失时保留未知状态，先核对请求记录，再按节点策略决定是否重新提交。

## 用户状态与内部字段映射

需求 V0.13 §9 的十种用户状态按下表统一映射。`status` 表示生命周期，`phase` 表示处理阶段；用户状态由二者推导，不再维护第三套独立终态。先判断等待或终态，仅在 `running` 时按 `phase` 显示执行阶段。

| 需求中的用户状态 | `status` | `phase` 与展示规则 |
| --- | --- | --- |
| 待执行 | `queued` | 保存预计起始阶段或上次阶段，显示待执行 |
| 文件解析中 | `running` | `parse` |
| AI 分析中 | `running` | `plan`、`interpret` 或 `verify`，阶段详情区分计划、解释和核查 |
| 数据计算中 | `running` | `compute`，包含真实统计和按数据绘图 |
| 文献检索中 | `running` | `search` |
| 文档生成中 | `running` | `write` 或 `export`，阶段详情区分章节生成与文件导出 |
| 待补充资料 | `waiting_input` | 保留暂停时阶段，展示待补材料而非继续执行中 |
| 待用户确认 | `waiting_confirmation` | 保留暂停时阶段，展示待确认内容 |
| 已完成 | `succeeded` | 保留最后阶段，显示完成及成果入口 |
| 执行失败 | `failed` | 保留失败阶段，显示失败原因与允许的下一步 |

`interpret` 是为已实现的解释步骤补充的阶段标识；以上阶段枚举在接口与前端共享。取消状态如获准再扩展，不能挤占这十种必需状态。投稿、返修、录用和评审通过仍是独立项目进展。

## 四、验收

验收先使用专用测试库、合成材料及模拟供应商响应。真实模型联调使用独立项目和明确预算；当前文档编写不运行服务或发起请求。

- [ ] S02-QA01 重复提交和重复消息只产生一个逻辑任务成果；各次尝试与事件仍可追溯。
- [ ] S02-QA02 分别在提交事务后、排队后、执行中和产物保存前中断进程，恢复后状态与产物一致。
- [ ] S02-QA03 等待任务不占用 Worker；错误版本、跨用户和重复恢复请求被拒绝或幂等处理。
- [ ] S02-QA04 复核旧项目迁移前后统计来源、response ID、PNG/DOCX 哈希及下载行为，无新增模型生成请求。
- [ ] S02-QA05 模拟调用成功但响应遗失、容器过期和用量缺失，确认不会无限重试或将未知消耗记为零。
- [ ] S02-QA06 并发任务不能越过用户、项目或单任务预算；暂停保留已有成果，预算调整后的恢复有记录。
- [ ] S02-QA07 两个测试账号无法查看、恢复或下载彼此任务；恶意资料文本不能扩大模型工具权限。
- [ ] S02-QA08 检查脱敏后的请求样本与日志，确认无密钥及未选入任务的身份字段和研究原文。
- [ ] S02-QA09 用浏览器完成关闭页面、刷新、切项目、待办恢复、失败重试和预算不足流程，并复核中英文提示。
- [ ] S02-QA10 运行受影响的后端、前端测试及构建检查，记录真实 API 样例的模型、成本、结果与未覆盖限制。
- [ ] S02-QA11 逐一构造上表十种状态并核对API与中英文页面映射；等待、完成和失败优先于保留的阶段，不误显示继续运行，也不变更投稿或评审进展。
